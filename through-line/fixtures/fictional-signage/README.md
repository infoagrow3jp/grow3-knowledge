# 架空の1社（看板の製作・施工）

**実在の会社・人物とは無関係。** 数値・発言・日付はすべて架空の設定。
一本線の1〜7段が流れ、1段へ戻るところまで回るかを確かめるための通しデータ。聞き取りの結果と認定も架空。

`tools/build_fixture.py` で作る。MQ・G・1件あたりM は、正本の `financial_calc.py`（calc_mq）に通した出力。
制約資源あたりMQ とシナリオは、提案中の `proposals/constraint_calc.py` で計算した。

## あらすじ

- 数字：年420件、MQ 1億1,340万円、G 840万円。施工の応援外注費 960万円
- 流れ（4週間の実測）：設計 9件/週、製作 10件/週、施工 7件/週。製作完了から施工着手まで平均6.5日。班長の判断待ちは1件あたり2.1時間
- 現場：班長は図面に無い条件を当日に電話で確認している。製作は営業時間を渡していない。班員は班長に聞くまで待っている
- 因果：受け渡しで渡る現場条件の量 → 班長への確認件数 → 判断待ち → 施工の完了件数 → 年間の完了案件数（Q）
- 制約の仮説：施工工程の、班長の判断時間（確認中。支持まではしていない）
- 検証：4週間の追加実測／班長にモノサシ言語化シート／班員への聞き取り（すり合わせシート）／受け渡しで現場条件3点を渡す実験／制約資源あたりMQの算定

## 6段への受け渡し

先に ACT-005：施工班長が「モノサシ言語化シート」を書く。任せたい仕事は、施工当日の現場判断。

次に ACT-002：「判断の見え方・線のすり合わせシート v0.2」で聞き取る。

| 項目 | 内容 |
|---|---|
| 聞き取る場面 | 施工当日、図面に無い現場条件に気づいたとき、自分で決めて進めるか、班長に聞くか |
| 案件の選び方 | この場面で、班長が途中で口を出した、または手直しになった実案件を1件 |
| 本人／責任者 | 施工班員／施工班長 |
| 使う Lens | LENS-009、LENS-008 |
| 強まる結果 | 班長だけが見ている手がかりが複数あり、班員は自分で決めてよい範囲を班長より狭く置いている |
| 弱まる結果 | 班員も同じ手がかりを見ており、止まる理由が見え方でも相談の線でもない |

## 6段の結果（架空）

- 言語化シート：班長はモノサシを5つ書き、うち3つは班員に渡せていないとした
- すり合わせシート：袖看板の取付で、配線が届かず翌日に手直しになった案件。班員は取付位置の寸法だけを見て、班長に聞かずに進めた
- ズレた場所：情報はあったが、注意が向いていなかった（電源の位置は現場で見える）
- 仮説の動き：HYP-003（判断は班長がするもの、という前提）は弱まった。HYP-004（班長が見ているところが渡っていない）を新しく立てた
- 次に一つ試すこと：ACT-006
