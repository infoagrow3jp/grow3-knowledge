# 3診断 実装語と grow3-frameworks.md の同期メモ

## 目的

2026-08-11に本番化した3診断の正式名称・軸名称と、
`grow3-frameworks.md` に残る旧運用語を同期する。

実装を先に本番確定したため、現時点では `diagnostics/README.md` を実装語の正本とする。

## 同期対象

### 1. 第3部索引

旧：

`思考特性4象限（A/B/C/D）／行動スタイル3軸／欲求プロフィール（5欲求）`

新：

`思考特性4象限（A/B/C/D）／行動特性3軸／欲求プロフィール（5欲求）`

### 2. 思考特性4象限

旧定義にある：

`HBDI®の商標を避け「思考特性診断」`

は、画面上の正式名称を **「思考特性」** とした現在の運用に合わせて整理する。

理論源流がHerrmann型であること、HBDI公式診断ではないことは維持する。

### 3. 行動スタイル3軸

見出し：

旧：`行動スタイル3軸（自己表現・自己主張・柔軟性）`

新：`行動特性3軸（自己表現・自己主張・一貫・順応）`

定義：

旧：`行動スタイルは“外に出る振る舞い”`

新：`行動特性は“外に出る振る舞い”`

### 4. 第3軸

旧：

`柔軟性（グリーン #27AE60）：他人の考え・行動をどれだけ受け入れる意志があるか（強＝協調的・優柔不断／弱＝意志が固い・頑固）`

新しい実装定義：

**一貫・順応**

`自分の基準を保つか、状況や相手に合わせて組み替えるか`

- 一貫寄り：一度決めた方針や自分の基準を保ちやすい
- 順応寄り：状況・相手・新情報に合わせて組み替えやすい

どちらかを能力的に高い／低いと評価しない。

### 5. 接続表現

`思考特性4象限・行動スタイル3軸`
→
`思考特性4象限・行動特性3軸`

へ同期する。

## 同期時の注意

- 理論そのものを作り替えない
- 実装名称との矛盾だけ解消する
- 「柔軟性が高い＝良い」という能力評価に戻さない
- 3診断は独立箱ではなく、同じ人物を見る3レンズとして扱う
