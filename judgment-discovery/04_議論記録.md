# D. マルチエージェント議論記録

作成：2026-10-25　状態：作業記録

## 1. 実施の形

Claude Code のサブエージェント機能で、4つの役割を**別々のコンテキスト**で動かした。単一エージェントの視点の切り替えではない。各エージェントは自分の担当の指示と共通ブリーフだけを受け取り、第1ラウンドでは他のエージェントの報告を読まないよう指示した（読んだかどうかを技術的に遮断する仕組みはなく、指示による分離である）。

| 役割 | 担当 |
|---|---|
| A 認知心理学・熟達研究者 | 判断の認知過程、暗黙知の引き出し方、内省の限界 |
| B 組織開発・経営システム研究者 | 目的・目標・価値観、評価・権限との整合、短期と長期、部分と全体 |
| C 現場実務・研修設計者 | 中小企業で回る問い・ワーク、プロトタイプの素案 |
| D 批判的検証者・方法論研究者 | 反例、競合理論、誘導・後付け・熟練者＝正解の前提への批判 |

| ラウンド | やったこと | 記録 |
|---|---|---|
| 1 独立調査 | 各自が文献を調べ、論点・方法・根拠・仮説A〜Eの評価・応用案を提出 | `agents/round1_A〜D.md` |
| 2 相互批判 | 他の3人の報告を読み、概念の混同・根拠の弱さ・現場での使いにくさ・代替案・見落としを指摘。他者の重要文献を1人2〜7件ずつ検索で裏取り | `agents/round2_A〜D.md` |
| 3 再提案 | 自分への批判を読み、変えた箇所と理由、受け入れなかった批判と理由、根拠の訂正、修正案、残る対立点を提出 | `agents/round3_A〜D.md` |
| 4 統合 | メインエージェントが統合。対立は無理に統一せず、§4・§5 に残した | 本書と 01〜10 |

`agents/` の報告は原文のまま収めた。ただし、リポジトリの出荷前検品（`scripts/pre-delivery-check.sh`）が止める語が第1ラウンドの2ファイルに計5か所あり、それぞれ「未決」「暫定の当てはめ」に置き換えた。意味は変わらない。

## 2. 各エージェントの主要提案の変化

### A 認知心理学・熟達研究者
- **第1ラウンド**：「なぜ」ではなく「見たもの・予期・選んだもの」を聞く。手順「比べる・選ぶ・当てる」（1条件だけ変えたカード4〜6枚と対照カード、事前に書く予測、初心者にも同じカードで選ばせる）。モノサシ3分類に「予期」の受け皿がないと指摘。
- **受けた批判**：カードは面談の途中でしか作れず準備30分に収まらない（C）。初心者に熟練者の選択を正解として見せている（B・C・D）。予測が当たるのは記述の確認で、良い基準の確認ではない（B）。Ericsson & Simon の根拠は主に同時報告で、事後の回想には及ばない（B・D）。CTA訓練のメタ分析をS1とするのは強すぎる（B・D）。
- **第3ラウンド**：カードを標準から外し「1件ずつ聞く・1つだけ戻す・先に書いて当てる」に変更。素材は実案件の記録と本人の言葉だけ。予測は次の実案件で行い、本人に見せず、判定は聞き手以外の人がする。冒頭で判断点を振り分ける3問を追加。「予期」の分類追加案は取り下げ、観察ポイントの文型を広げる案だけを残した。
- **受け入れなかった批判**：発見の段階で本人の実案件2件の違いを聞くことはやめない（比較で区別を引き出す方法は知識獲得研究の標準手法でもあるため）。

### B 組織開発・経営システム研究者
- **第1ラウンド**：価値観を共有しても判断は揃わない。揃えるのは衝突場面の判例と境界のルール。目標・評価・指標は本人の基準を上書きする。見直し条件はメタ基準として4点セットへ。2段の診断（基準の問題4種／COM-Bの仕組みの問題）と「Kerr テスト」の問い。
- **受けた批判**：Bardi & Schwartz の解釈が逆向きで、個人の水準から組織の水準を推論している（D）。経営陣の戦略ルールの研究を社員の判断が揃う根拠に使っている（A・C）。Kerr テストは本人に因果を推論させる問いで上司の前では歪む（A・D）。添え書き4つは重い、現場社員への具体的な問いがない（C）。判例も結果バイアスを受ける（D）。
- **第3ラウンド**：Bardi & Schwartz と Commander's intent の数値を根拠から外した。診断を3問（似た2件で対応が一貫しているか／書類と記録でぶつかるか／衝突を会社が決めているか）に縮め、本人には過去の出来事の想起だけを聞く。必須の添え書きは「ぶつかったらどちらを取るか」1つ。標準化・事例で共有・裁量の判定を4問で示した。判例は結果ではなく判断した時点の記録で残す。
- **受け入れなかった批判**：責任者の認定は検証の不足ではなく、トレードオフを決める正当な規範の決定である（Dの第1ラウンドへの反論。Dも第3ラウンドで受け入れた）。

### C 現場実務・研修設計者
- **第1ラウンド**：負担は「話すこと」ではなく「一般化」と「理由の説明」から来る。答えの形を「選ぶ・指さす・はい／いいえ」にする。発見は本人の記憶の2件（すんなり／手こずった）、用意した事例は教材化の段階へ。5分・15分・30分版の素案。方法 F〜I（物・写真・日報／並べ替え／3枚比べ／新人の目）を追加。
- **受けた批判**：3つの版とも締めが「合ってます？」の念押しで、自分の原則に反している（A・D）。15分版で話すのは上司で、出るのは上司の見立て（D）。確かめる前の候補を△の人に渡す手順は07段の禁止に反する（D）。30分版の2件を結果で名付けている（D）。「動けなかった理由」カードに能力・基準・仕組みが混在（B）。ShadowBox の28%改善は確認できない（A・B・D）。
- **第3ラウンド**：見つける手順と確かめる手順を分けた。締めは「記録の言葉の訂正」だけにし、確かめは聞き手が先に書く予測メモと、30分版の競合する2案で行う。15分版の出力は「上司の見立て」としてモノサシの候補に入れない。30分版は結果に関係なく記録3〜4件を持ってきてもらう。カードを10枚に作り直した。
- **受け入れなかった批判**：本人への Kerr テスト（抽象度が高く、上司の前では答えが出ない）。聞き取り前の独立の振り分けの段（記録が少ない会社では回らない）。Dの6つの確認を標準にすること。

### D 批判的検証者・方法論研究者
- **第1ラウンド**：熟練者の判断の記述と組織の規範が1本の線でつながっている。「認定」は承認で検証ではない。理由は予測の形に書き直して当たるかで確かめる。聞き取りの前に判断点を「なくす／支える／任せる」に振り分ける。6つの確認と確からしさの4段階。反証できる文型（場面／手がかり／境界／対応／予想される結果／例外）。
- **受けた批判**：6つの確認は重く、2人目の熟練者は最も必要な場面にいない（A・B・C）。仮説の段階で育成に使えないとしたのは承認済みの07段より厳しい（C）。確認は記述の一貫性しか見ておらず、責任者の認定はトレードオフを決める正当な役割（B）。「並べると区別を作る」は根拠以上に強く使っている（A）。
- **第3ラウンド**：必須の確認を3つ（例外を聞く／次の実案件で予測が当たるか／評価とぶつからないか）に絞り、残りは任意。育成での使い方は07段のとおりに戻した。軸を3つ（記述の確からしさ／規範としての選択／組織での扱い）に分け、モノサシの種類ごとに何が確かめを担うかを分けた。業務の基準に使う前の確認は、案①（判断材料として示すだけ、既存ルールは変えない）と案②（認定の条件にする、既存ルールより厳しい変更案）の2案にし、案①を勧めた。
- **受け入れなかった批判**：確かめを本人に隠すこと（「新人に渡して使えるかを一緒に試す」と伝える形にする）。2人目の熟練者を社外に頼むこと（守秘に触れる）。

## 3. 4人が独立に一致した点（採用）

1. 「なぜそうしたか」「判断基準は何か」を本人に説明させない。聞くのは「何をしたか」「その直前に何を見聞きしたか」「この後どうなると思ったか」。まとめるのは聞き手。
2. 依頼者の仮説Aの6分類は、新しい分類として台帳に足さない。既存の器への対応表と、面談者の聞き漏れの確認として使う。
3. 「見直す条件」は判断の中身ではなく、基準の寿命に関するメタ基準。4点セットと `next_review_trigger` が受け皿。
4. 本人の同意（「合ってる」）は確からしさの証拠に数えない。聞き手の翻訳の誤りを直してもらう機能としてだけ使う。確かめは、聞き手が事前に書いた予測が次の実案件で当たるかで行う。
5. 価値観は本人に聞いて集めない。ぶつかった場面で何を取り、何を捨てたかから読む。トレードオフを含む選択ルールは、熟練者から写すのではなく責任者が目的に照らして決める。
6. 評価との矛盾は、本人に問わず、評価表・目標設定表と候補を面談者が書類で突き合わせて見つける。
7. 新しい台帳・欄は作らない。追記が要るものは `extensions` で試してから判断する。

## 4. 修正の過程で解消した対立

| 対立 | どう解消したか |
|---|---|
| 確かめの重さ（Dの6つ vs Cの最小） | 必須3つ＋任意3つ。重い確かめは評価に使う前と、外れ・不一致が出たときだけ |
| 認定は検証の不足か、規範の決定か（D vs B） | 軸を3つに分けた。観察ポイントは記述の確からしさ、トレードオフの選択ルールは責任者の規範の決定、相談線は既存の4基準と権限の確認が担う |
| 候補を育成に使える時点（D vs C） | 既存の07段のとおり（候補の段階から暫定で使える）。Dが撤回した |
| 規則性・フィードバックの弱い判断点を対象から外すか（A・D vs C） | 外さない。その条件は選択ルール（結論）にだけ当て、観察ポイントは育成の暫定として採ってよい。選択ルールは責任者が決める |
| カードを作るか（A vs B・C・D） | 標準から外した。本人の言葉から口頭で1つ戻す問いと、本人が触れなかった条件の対照の問いで代える。カードは認定後の教材として |

## 5. 残った対立（統一しない）

それぞれ、決着に必要な証拠を 08 の検証計画に組み込んだ。

| # | 対立点 | 立場 | 決着に必要な証拠 |
|---|---|---|---|
| ① | 発見の段階で事例を並べて比べてよいか | A・C：本人の実案件なら、1件ずつ再現した後に並べてよい。D：本人の実案件は認めるが、用意した事例は1件ずつ。比較は区別をその場で作るおそれ | 同じ判断点で「並べる」と「1件ずつ」の両方を試し、出た仮説が次の実案件の予測をどれだけ当てるかを比べる（08 試行3） |
| ② | 「役に立つ基準」を何で確かめるか | A・D：記述の確認（予測）の後に認定。B：熟練者に近づくことを基準にする限り熟練者が正解のまま。後で出る結果（手直し・クレーム・相談の遅れ）で見るべき | 確認を通った手がかりを渡した初心者で、後で出る結果が減るか。1社では件数が足りず、複数の顧問先で同じ型の判断点を集める必要がある |
| ③ | フィードバックのある判断なら熟練者の直感を信頼してよいか | A・D：規則性とフィードバックがあれば採る価値がある。B：返っているのが目標の数字なら、指標への適応を学んでいるだけかもしれない | 熟練者の判断を、すぐ返る指標と、遅れて出る結果の両方と照合し、評価が分かれる判断点があるか |
| ④ | 評価との矛盾をどう見つけるか | B：責任者に直接1問で聞く（本人には聞かない）。C：本人への Kerr テストは不可。書類照合と、1件の出来事についてのカード | 同じ会社で両方を行い、見つかった矛盾が具体的な判断点の修正につながった件数 |
| ⑤ | 確かめを本人にどこまで見せるか | C・A：予測の紙は本人に見せない。D：隠さず「新人に渡して使えるかを一緒に試す」と伝える | 両方の伝え方で、熟練者から出る事例の具体さと、次回の協力の有無 |
| ⑥ | 誰が実施するか | C：日常で回すのは管理職。A：掘り下げる30分版には面談の技術が要る | 管理職の5分版を数回行った場合と、面談者の30分版を1回行った場合で、確認を通る候補の数 |
| ⑦ | 責任者＝熟練者のときの自己認定 | B：理由の記録と書類照合で足りる。D：自分の見方を自分で正当化する余地が残る | 責任者が熟練者本人である案件とそうでない案件で、予測の外れ方と、△の人が使えた割合 |
| ⑧ | 目的・価値観を現場の問いに入れるか | B：◎どうしの違いを会社の型にするとき価値観による選択が要る。C：それは責任者への確認で扱い、現場の問いには入れない | 責任者に渡した「両方とも結果を出しているやり方」の件数と、責任者が決められたか |

統合では、⑤ は「予測の紙は見せない（C・A）」と「目的は隠さず『新人に渡して使えるかを一緒に試す』と伝える（D）」を両立させた。両者は対立しないと判断した。他は統一していない。

## 6. この議論の限界

- 4人とも同じ基盤モデルで動いている。役割と指示は分けたが、同じ訓練データに由来する見落とし（同じ文献を知っていて、同じ文献を知らない）は、相互批判でも消えにくい。
- 文献の裏取りは、検索結果の書誌・要旨の水準どうしの照合で、本文と照らしたものではない。
- 実在の現場での試行は1件もない。すべての「現場で使えるか」の評価は、実務上の仮説（S5）である。
