# 最終報告：判断基準の発見・共有・活用

作成：2026-10-25　状態：検討結果の報告（正本ではない。既存資産は変更していない）

## 0. 結論

**判断基準をうまく説明できない人から手がかりを取り出すには、「判断基準は何ですか」と聞くのをやめ、当時の記録を手元に置いて「最初に何をしましたか」「その直前に何を見ていましたか」だけを聞く。** まとめるのは聞き手で、確かめは本人の「そうそう」ではなく、聞き手が先に書いた予測が次の実案件で当たるかで行う。

このやり方の部品（実案件の再現、手がかりを付けた振り返り、比較、予測による確認）は、それぞれ既存研究に根拠か先例がある。ただし、組み合わせた手順が中小企業の現場で「これまでより少ない負担で、他の人に役立つ手がかり」を出せるかは、まだ1件も試していない（実務上の仮説、S5）。08 の計画で、1社・1判断点・2か月から確かめる。

既存の器（モノサシ台帳、すり合わせシート v0.2、統制深度、4点セット、仕事マップ、Practice Lens）で、受け皿はほぼ足りていた。新しい台帳・分類は作っていない。足したのは、v0.2 の後に行う追加の手順（06 の30分版）と、日常の5分版、研修の15分版、確かめの最小構成（必須3つ）だけである。

## 1. 14章の問いへの回答

### 問1 判断基準とは何か。判断材料・判断過程・価値観とどう違うのか

「判断基準」の一語には、少なくとも5つのもの（何を見るかの**手がかり**、どこで対応を変えるかの**境界**、両立しないときの**優先**、組織としての**規範・規則**、なぜそうするかの**価値観**）が入っている（02 §2、エージェントD）。この方法論では、既存のモノサシと同じものを指し、分析者が次の形で書く。

> 〈場面〉で〈手がかり〉が〈境界〉を超えたら〈対応〉する。そうしないと〈予想される結果〉になりやすい。ただし〈例外の条件〉のときは除く。

- **判断材料・手がかり**は、この文の〈手がかり〉の部分で、モノサシの観察ポイントに当たる。本人に聞いてよい部分である。
- **判断過程**は、事実→着目点→解釈→先読み→判断→行動の流れ（v0.2 の再現の順、状況認識の3段階とほぼ重なる）で、「どこで落ちたか」を見る道具であり、会社に残すものではない。
- **価値観**は、本人に聞いても判断を説明しない（どの会社も「お客様第一」と言う）。ぶつかった場面で**何を取り、何を捨てたか**からだけ読む（07 事例1 §1-6 の対応表）。

もう一つの区別は、同じ文が「この人はこう判断している」（記述）にも「会社としてこう判断する」（規範）にも読めることである。記述は予測で確かめ、規範は責任者が目的に照らして決める（04 §4）。

### 問2 現場の人が判断基準を言語化できないのはなぜか

主な理由は3つある。
1. **熟練するほど、判断は状況の見分けとして起こり、比べた選択肢を思い出せない。** 自然な状況での熟練者は、状況を典型として見分けると妥当な対応が1つ浮かび、それを使う（RPD）。「どれと比べてそれを選んだか」は、そもそも起きていないことが多い（S2）。
2. **「なぜ」と聞かれると、実際の過程ではなく、もっともらしい理屈で答えてしまう。** 理由の報告は暗黙の因果理論に基づくことがある（03 の C1、S1〜S3）。言えないのではなく、言えても当たっていない可能性がある。
3. **負担は「話すこと」より「一般化」と「理由づけ」から来る。** 1回の出来事を話すことはできても、「いつもは〜」「なぜなら〜」とまとめる瞬間に詰まる（エージェントC、S5）。

加えて、言語化しにくいものの一部は、身体や関係に埋め込まれた技能（暗黙知の第3類型）で、言葉では移せない。これは観察と共有経験で移す。

### 問3 言語化を要求せずに判断基準を発見する方法には何があるか

05 で11の方法を比べた。要求する言語化の種類で分けると次のとおり。

| 本人に求めること | 方法 |
|---|---|
| 指さす・持ってくる | 物・写真・日報から入る（F）、行動観察・動画（E） |
| 1回の出来事を話す | 実際の出来事の再現（A、CDM 型、v0.2） |
| 違いを指す | 本人の実案件2件の比較（B1）、3枚比べ（H） |
| 3択で答える | 条件を1つ戻す問いと、対照の条件の問い（C） |
| 選ぶ・並べる | 用意した事例の比較（B2）、選択肢の並べ替え（G、ShadowBox 型） |
| 他人の見落としを言う | 新人の目で聞く（I、ACTA の知識監査の簡易版） |
| 何もしない（周囲が話す） | 熟練者と初心者の比較を上司が語る（D、15分版。出るのは上司の見立て） |

依頼者の仮説E（①出来事を集める→②比べる→③条件を変える→④選ぶ→⑤分析者が仮説化→⑥本人と検証）は、知識獲得研究の「直接尋ねずに推論過程を明らかにする作為的課題」の系譜にある（Hoffman ら 1995）。方向は支持できる。修正は2点で、③を聞き手が作った事例ではなく本人の言葉から1つ戻す問いと対照の問いにすること、⑥を本人の同意ではなく予測の的中で行うことである。

### 問4 その中で、中小企業の現場に最も導入しやすいのはどれか

**日報や記録の1行から入って1件の出来事を短く再現し、聞き手が予測を1行書く組み合わせ**（06 の5分版）である。準備は日報を手元に置く程度、聞き手の技術は手元カードで補える範囲、既存の1on1に乗る。
ただし、5分版で出る手がかりは少なく、聞き手が評価者を兼ねると上司の期待に寄った答えになりやすい。属人化した仕事を掘り下げるには、Grow3 か社内の人事担当が行う30分版が要る。用意した事例や選択肢を使う方法（B2・G）は、発見ではなく、確かめた手がかりを教材にする段階で使う。

### 問5 現場での質問数や回答負担を、どこまで減らせるか

| 版 | 本人への質問 | 本人の作業 |
|---|---|---|
| 5分版 | 2問＋締め（前回の予測がある回は＋1問） | 日報の1行を指す、したことと直前に見たことを言う、メモの言葉を直す |
| 15分版 | 本人（◎の人）には聞かない。管理職に5つの指示 | ★をつける、最近の1回を順に話す、選択肢に○、確かめる1枚を選ぶ |
| 30分版 | 約10問。半分は3択か2択 | 記録を持ってくる、指さす、3択・2択で答える、新しい人が困るときを言う |

どの版でも、完成した判断基準の説明、「なぜ」の説明、「いつもは」の一般化は求めない。一方、**負担を下げた分、聞き手の側の規律**（戻す条件を本人の言葉から選ぶ、予測を先に書く、結果を最後まで聞かない）**が必要になる**。本人の負担は減らせるが、ゼロにはならず、負担の一部は聞き手へ移る（エージェントA）。所要時間は開発上の目標で、実測していない。

### 問6 抽出した判断基準の妥当性を、どう確認するか

必須は3つ、任意は3つ（エージェントDの第3ラウンド。06 に組み込んだ）。

| | 確認 | 文言・やり方 |
|---|---|---|
| 必須 M1 | 例外を聞く | 「これを新しい人がこのとおりにやったら、困るのはどんなときですか。」 |
| 必須 M2 | 次の実案件で予測が当たるか | 面談者が事前に「次に◯◯が起きたら△△にするはず」と書き、次の1on1で聞く。判定は面談者以外。外れは消さない |
| 必須 M3 | 評価とぶつからないか | 本人には聞かず、評価表・目標設定表と候補を書類で突き合わせる。責任者には直接1問で聞く |
| 任意 O1 | 他の人が使えたか | △の人に暫定で渡し、「使う場面はありましたか。使ってみてどうでした」 |
| 任意 O2 | 2人目が同じ判断をするか | 答えを伏せて1問。熟練者がいなければ中堅か責任者、それもいなければ3か月後の同じ本人 |
| 任意 O3 | 記録で順序を確かめる | 手がかりが行動より前にあったかを、書き込み・時刻で見る |

状態は3つの軸で持つ（新しい欄は作らず、既存の欄と `extensions` で）。

| 軸 | 段階 | 依頼の4状態との対応 |
|---|---|---|
| 記述の確からしさ | 仮説 → 本人確認済み（M1）→ 複数事例で確認済み（M2 で元の案件以外に当たり） | 「仮説」「本人確認済み」「複数事例で確認済み」 |
| 規範としての選択 | 責任者が決めた（理由を `certification.reason` に「何のために、何を捨てて」） | 「組織として承認済み」の中身 |
| 組織での扱い | 候補／認定／保留（既存の `state`） | 「組織として承認済み」＝認定 |

**確認の前から会社の公式基準として扱わない**ことは、既存の07段の用途ルール（育成は候補から暫定で、業務の基準は認定が必要、評価は認定＋人事制度設計OSの確認）で守られている。この提案は07段のルールを変えない。

### 問7 何を標準化し、何を事例で共有し、何を本人の裁量に残すべきか

判断点ごとに4問を順に当てる（05 §5、エージェントB）。

1. 失敗の非対称性が大きく、正解が外から決まるか（法令・安全・金銭）→ **標準化**（手順・チェック。熟練者からは採らず規程から書く）
2. 2つの正しさがぶつかり、会社として向きを決める必要があるか → **標準化（選択ルール）**（責任者が決め、理由を書く）
3. 何を見るかで結果が分かれるが、ルールにすると伝わらないか → **事例で共有**（2件の比較、写真、判断の例）
4. 規則性とフィードバックがあり、やり方の違いが結果を壊さないか → **裁量**（事後の振り返りだけを残す）

例（07 事例1）：工房に確認する前に確定の納期を言わない（標準化）／贈る相手のサイズが分かる物があるかを見る（事例で共有）／どのデザインを勧め、どう声をかけるか（裁量）。
規則性もフィードバックもない判断（長期の顧客関係、採用）は裁量に入れず、責任者が向きを決めて記録と照合する。現場に渡す言葉は既存の3語（必ず守ること／自分で決めてよいこと／ここからは相談すること）のままにする。言語化そのものが要らない部分（写真・実物で渡す、同行で移す）を残すことも、この区分に含まれる。

### 問8 目的・目標・価値観、時間軸、全体最適との関係をどう扱うか

**現場の社員に「何のため」「何を大切に」「長期的にどうか」を聞かない。** 建前が出るうえ、担当者は判断の時点で長期・全体の影響が見えていないことが多い（エージェントC・B）。代わりに次のように扱う。

- **目的**：段階ごとの具体の一言で採る（仕事マップ上段：「この段階で、お客様から言われて一番うれしい一言と、一番言われたくない一言は何ですか」）。モノサシには、責任者が「何のために、何を捨てて選んだか」を理由として書く。
- **目標**：判断を方向づけると同時に歪める（03 の C11〜C13）。候補を評価表・目標設定表と書類で突き合わせ、ぶつかれば評価・目標の見直しとして経営へ返す（07 事例1：月間売上の評価と「その日に決めてもらわない」がぶつかった）。
- **価値観**：ぶつかった場面で何を取ったかから読み、価値観と判断事例の対応表にする（07 事例1 §1-6）。価値観を掲げるだけで判断が揃うかは、検証できていない（C18、S5）。
- **時間軸・全体最適**：「後で・他の場所で効くもの」を観察ポイントとして採る（「この仕事を急いで、あとで別の工程やほかのお客様が困ったこと、最近ありましたか」）。「それをやらなかったら何が起きますか」の答えが遠い判断は、熟練者から写さず、責任者が選択ルールとして決める。結果が遅く返る判断では、熟練者の直感の正しさが保証されないからである（C5）。仮説Cは「熟練者から学ぶ」前提を内側から崩す、という点は明示しておく（エージェントD）。

### 問9 判断基準があっても実行できない場合、何を診断すべきか

3問で見る（05 §6、エージェントB）。
1. **対応が一貫しているか**：似た2件で、本人の対応が同じか（言えるかではなく、していることで見る）。一貫していなければ、基準が無いか届いていない。
2. **書類と記録でぶつかるものがあるか**：評価表・目標設定表・手当の規程・権限規程・受け渡しの記録と候補を並べる。本人には「前にそうしたとき、誰かに何か言われましたか」だけを聞く。
3. **衝突を会社が決めているか**：決めていなければ、基準づくりではなく経営の選択の問題。決めるまでの間は、4点セットでその判断点を一時的に相談線へ下げる。

本人が1件の出来事について選ぶ「やろうと思ったのにできなかった理由」カード（10枚）は、能力（どこを見るか／つかめなかった／やったことがない）・基準（優先／完了が決まっていない）・仕組み（情報／権限／時間・人手／評価・指示／聞ける人）に分かれる（`agents/round3_C.md` §5）。同じズレが別の人・別の案件で2回出たら、人の判断ではなく仕組みの問題として扱い、業務の設計（マニュアルの1行、共有表、受け渡し）を先に直す（07 事例3）。

### 問10 新しい研究や現場の経験によって、基準や方法論をどう更新するか

09 のとおり。入口は既存の研究ダイジェストと、実案件の記録（予測の当たり外れ、使えたか）の2つだけ。更新の単位は論文ではなく、03 の主張（C1〜C20）・02 の定義・06 の問いの文言で、変更履歴に「内容・理由・根拠」を残す。現場の手順は、現場の試行の結果か、確認水準の高い反証が出たときにだけ変える。主張台帳・定期実行の仕組みは作らない。

## 2. 明日、現場で一つだけ試すなら

**部下1人との1on1の最後の5分で、日報を1枚だけ開いて、次の2つを聞く。**

1. 「この2週間の日報で、途中で手を止めたり、確かめ直したり、人に聞いたりしたところを、1か所指してもらえますか。」
2. 「そのとき、最初に何をしました？　その直前に、何を見たり聞いたりしていました？　覚えていなければ『覚えてない』で大丈夫です。」

聞いたことは、本人の言葉のまま1行メモにし、「言葉が違うところがあれば直してください」とだけ返す。「なぜ」は聞かない。褒めもしない（「ありがとうございます。メモしておきます」）。
面談の後で、メモの横に**予測を1行**書く。「次に□□が起きたら、この人は××するはず」。本人には見せない。
次の1on1で「前に話してくれた件、その後、同じような場面はありましたか。そのときはどうしました？」と聞き、当たったか・外れたか・場面がなかったかを書く。

準備は日報を開くことだけで、聞く側に必要なのは「なぜを聞かない」の1つの規律である。これが回れば、出てきた手がかりを30分版で掘り下げる対象が見えてくる。回らなければ（「特にないです」が続く、予測がまったく当たらない）、それ自体が08の判定線に当たる最初のデータになる。

## 4. やっていないこと・確かめていないこと
