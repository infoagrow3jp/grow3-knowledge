# F. 現場向けプロトタイプ（5分版・15分版・30分版）

作成：2026-10-25　状態：試作（実地での試行はまだない）

所要時間は開発上の目標で、実測値ではない。どの版も試して直す前提で作っている。
エージェントCの第3ラウンドの版を土台に、エージェントDの必須の確認（例外の問い・事前の予測・評価との照合）と、エージェントAの判断点の振り分けを組み込んだ。

## 0. 3つの版に共通する約束

1. **「なぜ」を聞かない。** 完成した判断基準も説明させない。
2. **行動を先に聞き、見たもの・聞いたものはその後に聞く。** 「覚えていない」を答えとして認める。
3. **記録や物から入る。** 日報・伝票・写真・チャット履歴など、当時の痕跡を手がかりにする。
4. **案件を結果（うまくいった／いかなかった）で選ばない。** 結果は再現が終わってから聞く。
5. **聞き手は褒めない・評価しない。** 受け答えは「ありがとうございます。メモしておきます」。
6. **締めは同意の念押しにしない。** 本人に頼むのは「記録の言葉の訂正」だけ。確からしさは、聞き手が**事前に書いた予測**が次の実案件で当たるかで確かめる。
7. **「本人の言葉」と「聞き手の仮説」を別の列に書く。** ルールの形（〜のときは〜）は仮説の列にだけ書く。同じ型が2件以上出るまで、1件の出来事をルールにしない。
8. **目的は隠さない。** 本人には「新しい人に渡して使えるかを、一緒に試します」と伝える（予測の紙そのものは見せない）。
9. **候補の扱いは既存の07段のとおり。** 候補は育成に暫定として使ってよい。守るべき決まりとしては伝えない。業務の基準にするのは責任者が認定したものだけ。
10. **AI は競合する仮説を2〜3案出す役。** 予測を立てること、どの仮説を採るかを決めること、認定はしない。AI が書いた文には作り手を記録する。

### 聞き手の手元カード（3つの版で共通、名刺大）

```
□ 最初に「何をしましたか」→ 次に「その直前に何を見ていましたか」
□ 「なぜ」は聞かない
□ 結果は最後まで聞かない
□ 戻す条件は本人の言葉から選ぶ。対照の条件も1つ聞く
□ 予測は先に紙に書く。本人には見せない
□ 褒めない。「ありがとうございます。メモしておきます」
□ 締めは「言葉が違うところを直してください」
```

## 1. 5分版「今週の1場面」

**使う場面**：隔週の1on1の最後の5分、日報への返信。人事評価の面談とは別の日。聞き手は、できれば直属の評価者でない人（先輩、隣の部署の管理職）。直属の上司が聞くときは、メモに「聞き手＝評価者」と書く。

**必要な準備**（目標2分）：本人の直近1〜2週間の日報を手元に置く。前回の予測メモがあれば、その1行を見ておく。

**提示する質問**（問1は A と B を1回おきに交互に使う。頻度は月2回まで）

| | 文言 |
|---|---|
| 問1-A | 「この2週間の日報で、途中で手を止めたり、確かめ直したり、人に聞いたりしたところを、1か所指してもらえますか。」（日報がなければ「この2週間で、そういう場面を1つ教えてください。」） |
| 問1-B | 「この2週間で、いつも通りに済んだ仕事を1つ選んでください。その仕事で、やろうと思えばできたけれど、やらずに済ませたことはありますか。」 |
| 問2 | 「そのとき、最初に何をしました？　その直前に、何を見たり聞いたりしていました？　覚えていなければ『覚えてない』で大丈夫です。」 |
| 問3（前回の予測メモがあるとき） | 「前に話してくれた〇〇の件、その後、同じような場面はありましたか。そのときはどうしました？」 |
| 締め | 「メモにはこう書きました。『〇日、△△の作業で、□□を見て、手を止めて××さんに聞いた』。言葉が違うところがあれば直してください。なければこのまま残します。」 |

問1-B は、例外の判断ばかりに偏らないように、いつも通りうまくいっている日の取捨選択を拾うために入れている（Safety-II の視点）。

**回答者の作業**：日報の1行を指す、したことと直前に見聞きしたことを言う、メモの言葉を直す（直さなくてよい）。

**聞き手の作業**：次の5列でメモを書く。仮説と予測の列は本人に読み上げない。

| 日付 | 場面（日報の参照先） | 本人の言葉そのまま | 聞き手の仮説 | 次の予測 |
|---|---|---|---|---|
| 10/21 | 日報10/21「B社出荷前」 | 「箱を見たら前回とラベルの位置が違ってたので、止めて事務に聞いた」 | ラベル位置の違いを、仕様変更の手がかりとして見ている？ | 次にラベルや表記が前回と違う荷が来たら、出荷前に止めて確認するはず |

問3の答えで、前回の予測の「当たり／外れ／場面なし」を記録する。外れは消さずに残す。

**AI に任せられる作業**：月2件程度のメモから、聞き手が水を向けていないのに同じ手がかりが繰り返し出ているかの印付け、聞き手の仮説に対する競合する仮説2〜3案、「動けなかった理由」に当たる話の抜き出し。

**出力物**：5列のメモ（1件1行）と、予測の当たり外れの記録。評価者が聞いたメモは育成（暫定）にだけ使い、モノサシの候補にするのは、別の経路（30分版、または評価者でない聞き手）で同じ手がかりが出たときだけ。メモの保存場所・閲覧者・保存期間は社内規程で決める（1on1のメモは人事評価に転用されうる個人の記録なので、社労士業務として依頼者が整えられる）。

**想定される失敗と手当て**

| 失敗 | 手当て |
|---|---|
| 「特にないです」が続く | 問1-B に替える。日報の1行を聞き手が指すのは最後の手段（評価の目線が入るため） |
| つい「なぜ？」と聞く | 手元カードの1行目に戻る |
| 聞き手が褒め、次から部下が「役に立ちそうな話」を選んでくる | 受け答えを中立の一言に固定する |
| 部下が上司の期待する答えに寄る | 消すことはできない。「聞き手＝評価者」の記録で、出力の用途を育成に絞る |
| 毎回同じ問いで、本人が「違うこと」を探して話すようになる | 問1の A/B を交互にし、月2回までにする |

**次の改善方法**：2〜3か月試して、(a) 予測の当たり／外れ／場面なしの件数、(b) 評価者が聞いたメモと評価者でない人が聞いたメモで手がかりの具体さに差があるか、(c) 実際の所要時間、を数える。当たりがほとんどないなら、問2の聞き方か予測の書き方を見直す（08 の試行2）。

## 2. 15分版「◎と△のやり方の違い」

**使う場面**：仕事マップのワークで、上段（段階）・中段（具体的な仕事）・担当者と◎○△まで記入した後。管理職研修では、自分の部下が担う仕事を対象にする。2〜3人1組。人事評価の時期と重なる月には行わない。

**この版で出るものは「上司の見立て」である。** 話すのは管理職で、◎の本人ではない。他人の判断についての説明は、本人の手がかりより、上司が持つ熟達のイメージになりやすい（03 の C1）。出力はモノサシの候補に入れず、◎の本人に確かめる対象を選ぶために使う。

**必要な準備**（講師、目標15分）
- 事前の経営者との打合せで決めた「今年いちばん止まると困る段階」を、マップの上段に太枠で囲んでおく。人による差が大きい判断ではなく、経営への影響が大きい判断から選ぶため（through-line 06段の「制約に効く判断の場面を1つ選ぶ」と同じ考え方）。
- 付箋3色（黄＝したこと、青＝止まる・聞く場面、白＝違いの種類）、「上司の見立て」と書いた枠シール。

**冒頭の一言（講師）**：
「◎○△は人の点数ではありません。今日は、◎の人と△の人で、やり方がどこで違うかを見ます。その違いが、見ているものの違いなのか、届いている情報や任されている範囲の違いなのかも、一緒に見ます。今日出るのは皆さんの見立てで、正解ではありません。」

**指示と問い**

| 手順 | 時間 | 文言 |
|---|---|---|
| 1 個人 | 2分 | 「太枠の中の仕事で、◎の人と△の人のやり方が違っていて、その違いが手直し・問い合わせ・納期の遅れなどの形で見える仕事に、★を1つつけてください。」 |
| 2 ペア | 5分 | 聞き手が聞く：「その仕事の最近の1回で、◎の人と△の人が、それぞれ何をしたかを、した順に教えてください。分からないところは『分からない』で大丈夫です。」→ 聞き手が黄の付箋に書く。端に「直接見た」か「たぶん」かを書く |
| 3 ペア | 3分 | 「△の人がやるとき、どこで手が止まったり、人に聞いたりしていますか。それ自体は悪いことではありません。」→ 青の付箋 |
| 4 ペア | 2分 | 白の付箋に、次のどれに近いか1つ○をつける：「見ているところが違う／届いている情報が違う／任されている範囲が違う／やったことのある回数が違う／分からない」 |
| 5 個人 | 3分 | 黄の付箋を下段の「上司の見立て」の枠に貼る。「この付箋のうち、来週、◎の人本人に1つだけ確かめるならどれですか。★をつけてください。」 |

**回答者（管理職）の作業**：★をつける、最近の1回のやり方を順に話す、違いの種類に○をつける、確かめる1枚を選ぶ。書くのはペアの聞き手。

**聞き手の作業**：付箋に書く。抽象語（丁寧に、しっかり、気をつける）が出たら「その日、◎の人がしたことを1つだけ言うと何ですか」で行動に戻す。ルールの形（〇〇のときは）は書かない。

**AI に任せられる作業**：マップと付箋の写真からの文字起こし、抽象語への印、「直接見た／たぶん」の比率、白の付箋の集計（会社全体で「情報が違う」「範囲が違う」が多い段階の一覧＝仕組み側の課題の候補）、Practice Lens の同じ観点のカードとの照合（講師の裏方。紙には載せない）。

**出力物**：「上司の見立て」の枠に付箋が貼られた仕事マップ（モノサシの候補には入れない）。◎の本人に確かめる1枚（翌週の5分版か、30分版の対象選びに使う）。白の付箋の集計は、統制深度・4点セット・受け渡しの見直しの材料として経営者へ返す。

**想定される失敗と手当て**

| 失敗 | 手当て |
|---|---|
| ◎の人が同じ研修に参加していて、名指しの場になる | ◎の本人がいる組は作らない |
| 付箋がほぼすべて「たぶん」になる | それ自体が情報（上司は◎の人の仕事を見ていない）として記録し、5分版の対象選びに回す |
| 「報連相」「確認」など全員がやることが出る | 「◎の人だけがしていること」に絞り直す（Practice Lens rubric 4） |
| 時間不足 | 削るなら手順3。手順4は仕組み側への出口なので残す |

**次の改善方法**：研修後1か月で、★をつけた1枚が◎の本人の確認でどうなったか（同じだった／違った／確かめられなかった）を数える。上司の見立てと本人の言葉の一致の程度が、この版の出力をどこまで信じてよいかの目安になる。

## 3. 30分版「記録を見て、2件を比べる」

**使う場面**：特定の人しかできない仕事、判断が難しい仕事。育休・退職・異動の引き継ぎ前。面談者（Grow3 または社内の人事担当）と本人の1対1。責任者は同席しない。既存のすり合わせシート v0.2 の後に行う**追加の手順**として扱う（v0.2 は対照案件の比較・反実仮想を行わないので、v0.2 本体の変更ではない）。

**必要な準備**（面談者、目標30分）

1. **判断点の振り分け（10分、責任者に電話で聞く程度）**
   - 「この判断は、月に何回くらいありますか。」
   - 「うまくいったかどうかは、いつ、何で分かりますか。」
   - 「失敗すると、何が起きますか。」
   - 安全・法令・金銭なら統制深度①として手順で扱い、この版の対象にしない。結果が遅い・まれな判断なら、観察ポイントは採るが、選択ルールは熟練者から写さず責任者に回すと決めておく（05 §4）。
2. **本人への依頼（1週間前、紙1枚）**：「この仕事の最近の記録（伝票・図面・写真・日報・メールなど）を、うまくいったかどうかに関係なく3〜4件持ってきてください。話す内容を考えてくる必要はありません。」
3. **面談者の手元**：仕事マップの該当行、v0.2 シート、付箋、予測を書く紙（本人に見せない）、評価表・目標設定表（面談後の照合用）。録音は本人の同意がある場合のみ。

**進行と問い**

| 時間 | やること | 文言 |
|---|---|---|
| 0〜2分 | 導入 | 「今日は〇〇さんのやり方の正解を決める場ではありません。記録を見ながら、そのとき何をしたかを順に教えてください。うまく説明しなくて大丈夫です。出てきたものは、新しい人に渡して使えるかを、一緒に試します。」 |
| 2〜4分 | 2件を選ぶ | 面談者が記録を見て、やり方が違っていそうな2件を選ぶ。「この2つについて、順番に聞かせてください。」（どちらがうまくいったかは聞かない） |
| 4〜14分 | 1件目を丁寧に（1件ずつ、並べない） | 「この記録の中で、最初にいつもと違うことをした（手を止めた）のはどこですか。指してください。」→「その前に、何がありましたか。何を見たり聞いたりしていましたか。覚えていなければ大丈夫です。」→「その後、どうなると思っていましたか。」→「それで、何をしましたか。」 |
| 14〜17分 | 2件目は1問 | 「こちらの記録では、同じところでどうしましたか。」 |
| 17〜19分 | ここで初めて並べる | 「2つを見て、違うところを指してください。」（何を違いとするかは本人に任せる。この段で新しく出た違いは、付箋の色を変えて記録する） |
| 19〜24分 | 確かめ（面談者は先に紙に「◯◯なら変わる、□□なら変わらないはず」と書く） | 「もし記録2のときに、◯◯だけが記録1と同じだったら、どちらのやり方にしたと思いますか。記録1のやり方ですか、記録2のやり方ですか、分かりませんか。」→「もし□□だけが違っていたら、どうですか。」（同じ3択）→「それをやらなかったら、何が起きますか（起きそうですか）。」 |
| 24〜28分 | 競合する2案と例外 | 「A：『◯◯を見たら、△△にする』。B：『□□のときに、△△にする』。どちらが近いですか。どちらでもないですか。」→「これを新しい人がこのとおりにやったら、困るのはどんなときですか。」 |
| 28〜30分 | 次の1回 | 「次にこの仕事があったとき、1つだけ確かめるとしたら、どの記録のどこですか。」（v0.2⑥） |

◯◯は本人が指した違い。□□は本人が触れなかった条件（担当者、曜日、数量など、面談者が記録から拾う）で、対照として聞く。□□でも「変わる」と答えたら、◯◯という説明は弱いと記録する。2案の両方に「近い」と答えたら、この確認には情報がないと記録し、次の実案件での予測に任せる。

**回答者の作業**：記録を持ってくる、指さす、したことを順に話す、3択で答える、2案から近い方を選ぶ、新しい人が困るときを言う、次に確かめる箇所を指す。

**聞き手の作業**：付箋の時系列化（v0.2 の流れ：事実→着目点→解釈→先読み→判断→行動。本人に分類させない）、結果を混ぜない、2件と□□を記録から選ぶ、事前の予測と競合する2案を作る（AI の下書きを使ってよい）。面談後に次を行う。
- 手がかりのうち、当時の記録（書き込み、撮影・送信の時刻）で行動より前にあったと確かめられるものだけを「そのときの手がかり」とし、他は「本人の振り返り」として残す。
- 「新しい人が困るとき」の答えを、文の「ただし（例外の条件）」に入れる。
- モノサシ3分類へ暫定で当てはめる。「やらなかったら何が起きるか」の答えが遠い（「いつか信頼が」）ものは、熟練者から写さず、選択ルールの候補として責任者に回す。
- 評価表・目標設定表と候補を書類で突き合わせる（05 §6 の問2）。
- 「動けなかった理由」に当たる話は、カード（05 §6）で記録する。
- 次の実案件の前に、予測を1行書く（「次に〇〇の場面が来たら、この人は△△するはず」）。当たり外れは、面談者以外の人（責任者、または記録）で判定する。

**AI に任せられる作業**：文字起こし、時系列カードの下書き、2件の差分表、記録から□□の候補を拾う、競合する仮説2〜3案、責任者に渡す1枚の下書き。**任せないもの**：事前の予測、どの仮説を採るか、本人への返し方、認定。

**出力物**
- 本人の言葉（「そのとき」と「本人の振り返り」の区別つき）
- 面談者の仮説（ルールの形、2〜3案、どれが残ったか、事前予測の当たり外れ、例外の条件）
- 責任者に渡す1枚：本人の見え、残った仮説、「やらなかったら何が起きるか」が遠い判断、◎の人どうしでやり方が違い両方とも結果を出している場合はその両方（どちらを会社の型にするかは責任者が決める）、評価表との矛盾
- 仕組み側の課題メモ、次の1回の確認事項（`monosashi_trial`）
- モノサシ台帳への記録：状態は「候補」。`source_case_count` には実案件だけを数える。予測の当たり外れ・文の作り手は `extensions.through_line` に書く（**変更案**。10 §3）

**想定される失敗と手当て**

| 失敗 | 手当て |
|---|---|
| 1件目の再現が14分で終わらない | 2件目と「新しい人」の問いを削る。19〜24分の確かめは削らない |
| 本人が記録を持ってこない | 仕事マップの「実際の出来事」欄か、面談者が事前に集めた手直し記録で代える |
| 手こずった件の話が他人のせいになる | 「そのとき〇〇さんがしたことは何でしたか」に戻す |
| 本人が「試されている」と感じる | 予測の紙は見せない。導入の一言と、最後の「どう使うかは責任者と相談して、使う前にお伝えします」（06段） |
| 2件が別の仕事・別の工程で比べられない | 依頼の紙に「同じ仕事の、同じ段階の記録」と書く |

**次の改善方法**：3〜5件試して、事前予測の的中、□□で「変わらない」が出た割合、2案の選び分けができた割合、次の実案件での当たり外れ、実際の所要時間を記録する（08 の試行1）。予測がほとんど当たらないなら、2件の選び方を見直す。

## 4. 3つの版の位置づけ

| | 5分版 | 15分版 | 30分版 |
|---|---|---|---|
| 誰が聞くか | 管理職・先輩 | 研修のペア（講師が進行） | 面談者（Grow3・人事担当） |
| 誰の判断か | 本人 | ◎の人（上司の見立てとして） | 本人 |
| 出るもの | 1件の出来事のメモと予測 | 確かめる対象の候補、仕組み側の課題の集計 | 仮説2〜3案、例外の条件、責任者に渡す1枚 |
| モノサシの候補にするか | 評価者以外が聞いたもの、または別経路で同じ手がかりが出たもの | しない | する（状態は候補） |
| 確かめ | 次の1on1での予測の当たり外れ | ◎の本人での確認 | 事前予測、対照の条件、競合2案、例外の問い、次の実案件での予測 |
| つながり | 30分版の対象選び、`monosashi_trial` の結果の回収 | 5分版・30分版の対象選び | モノサシ台帳、07段の用途の仕分け |

身体に埋め込まれた技能（移乗、溶接、包丁さばきなど）は、どの版でも取り出せない。観察と共有経験（同行・実演・やってみせる）で移す（暗黙知の第3類型）。
