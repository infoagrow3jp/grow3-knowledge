# F. 現場向けプロトタイプ（5分版・15分版・30分版）

作成：2026-10-25　状態：試作（実地での試行はまだない）

所要時間は開発上の目標で、実測値ではない。どの版も試して直す前提で作っている。
エージェントCの第3ラウンドの版を土台に、エージェントDの確かめ（K1〜K3）と、エージェントAの判断点の振り分けを組み込み、別コンテキストの査読（2026-10-25）で直した。

## 0. 3つの版に共通する約束

1. **「なぜ」を聞かない。** 完成した判断基準も説明させない。
2. **したことと、その直前に見聞きしたことを聞く。** 5分版は「したこと→見たもの」の順。30分版は記録を指してもらってから「見たもの→したこと」でよい。「覚えていない」を答えとして認める。
3. **記録や物から入る。** 日報・伝票・写真・チャット履歴など、当時の痕跡を手がかりにする。
4. **この方法で比べる2件は、結果ではなくやり方の違いで選ぶ。** 結果は再現が終わってから聞く。
   - **06段からの変更案**：既存の06段は「案件は結果で選んでよい（実際に判断のズレが起きた案件）」としている。この約束は30分版の追加の手順にだけ当て、v0.2 の聞き取りは06段のとおりに行う。06段そのものを変えるかは 10 §3 #2 で判断を待つ。
5. **聞き手は褒めない・評価しない。** 受け答えは「ありがとうございます。メモしておきます」。
6. **締めは同意の念押しにしない。** 本人に頼むのは「記録の言葉の訂正」だけ。
7. **「本人の言葉」と「聞き手の仮説」を分けて書く。** ルールの形（〜のときは〜）は仮説にだけ書く。1件の出来事をルールの形にしない。2件以上の実例がそろったら境界の仮説を検討し始めるが、それは検討の入口で、確定の条件ではない。ほかの条件で対応が変わった可能性を残しておく。
8. **目的は隠さない。** 「新しい人に渡せるものがあるかを探すために聞かせてください」と伝える（予測の紙そのものは見せない）。
9. **候補の扱いは既存の07段のとおり。** 候補は育成に暫定として使ってよい。守るべき決まりとしては伝えない。業務の基準にするのは責任者が認定したものだけ。
10. **AI は競合する仮説を2〜3案出す役。** 予測を立てること、どの仮説を採るかを決めること、認定はしない。AI が書いた文には作り手を記録する。

### 発見・抽出・確かめの段（版とは固定しない）

| 段 | すること | 次の段へ進む目安 | 使える場（固定しない） |
|---|---|---|---|
| 発見 | 手がかりの候補を見つける（どの記録の、どこで、何をし、その直前に何を見聞きしたか） | 同じ仕事・同じ段階で、対応が違った実例か、同じ手がかりがあったのに対応が違った実例がそろった | 5分版、15分版、30分版の前半、日報への返信 |
| 抽出 | 対応が違った実例を比べ、どの条件で対応が変わるかの仮説（境界の仮説）と、まだ否定できていない別の説明を2〜3案立てる | 仮説と別の説明が書けた。2件以上の実例は検討を始める入口で、確定の条件ではない | 30分版、または対応の違う実例がそろった後の1on1（5分を数回重ねてもよい） |
| 確かめ | K1〜K3（必要に応じて K4〜K6）で、仮説を支持する証拠と弱める証拠を集める | 確かめで基準が確定することはない。会社の決まりにするかは、責任者が規範として別に決める（認定） | 次の実案件、1on1、認定の場 |

どの段にいるかは、面談の長さではなく、そろった実例と確かめで決まる。5分版を重ねて対応の違う実例がそろえば、30分版を開かなくても抽出に進んでよい。反対に、30分版でも対応の違う実例がそろわなければ、発見で止める。

### 確かめ（K1〜K6）

| 記号 | 確かめ | 必須／任意 |
|---|---|---|
| K1 | 例外を聞く（「これを新しい人がこのとおりにやったら、困るのはどんなときですか」） | **モノサシ台帳に候補として載せる前**に必須 |
| K2 | 次の実案件での予測（下の手順） | 同上 |
| K3 | 評価表・目標設定表との書類照合と、責任者への1問 | 同上 |
| K4 | 他の人が使えたか | 任意（評価に使う前、外れ・不一致のとき） |
| K5 | 2人目が同じ判断をするか | 任意 |
| K6 | 記録で順序を確かめる | 任意 |

どの場で出た手がかりでも、K1〜K3 を済ませるまではモノサシの候補にしない（場ではなく、確かめの有無で決める）。

### K2 次の実案件での予測の手順

| 項目 | 決めること |
|---|---|
| 予測の対象 | 本人の対応の種類。事前に決めた選択肢（例：出す／止める／相談する／予約を取る／その他）から1つ。結果は予測しない |
| 場面の定義 | どの記録に何が現れたら「その場面が来た」とするかを、予測と同時に書く。対応を見てから場面かどうかを決めない |
| 事前の記録 | 日付、場面の定義、仮説による予測、仮説が無いとした場合の予測（いつも通りの対応）。本人には見せない |
| 一致の判定 | 予測した人以外が、記録で行う。先に場面が来たかを判定し、その後で対応を見る。記録が足りなければ「判定不能」とし、当たりにも外れにも数えない |
| 情報のある予測 | 仮説による予測と、いつも通りの予測が違う回だけを、仮説の証拠として数える。同じになる回は、当たっても何も分からないので別に記録する |
| 外れの扱い | 消さずに残し、次の見方で読む（重なってよい）：場面の定義がずれていた／手がかりはあったが別の条件で対応を変えた（抽出に戻す）／本人のやり方自体が変わった（指示・学習）／記録が足りなかった |
| 読み方 | 当たりは判断仮説を支持する証拠の一つで、仮説が正しいことの証明ではない。同じ結果を別の条件で説明できる可能性は残る。外れは仮説を弱める証拠。何件で仮説を捨てるかは、08 の暫定の判定線で決める |
| 望ましさとの区別 | 予測が当たっても、その判断が組織にとって望ましいことにはならない。望ましさは、K3、責任者の決定（理由つき）、後で出る結果（手直し・クレーム・相談の遅れ）で別に確かめる |

予測という方法の限界：いつも同じ対応をする仕事では当たって当然になる（情報のある予測だけを数えて一部を防ぐ）／聞かれたこと自体で本人の行動が変わる（反応性）／まれな判断は件数が足りない／判定する人が対応を見て場面を決めると当たりが水増しされる（場面を先に判定して小さくする）／一貫した悪いやり方でも当たる／予測しやすい定型の判断ばかりが残りやすい。

## 1. 5分版「今週の1場面」

**目的は手がかりの発見まで。** 判断が変わる条件は、ここでは決めない。メモが重なって対応の違う実例がそろったら、抽出に進む（§0）。

**使う場面**：隔週の1on1の最後の5分、日報への返信。人事評価の面談とは別の日。聞き手は、できれば直属の評価者でない人（先輩、隣の部署の管理職）。直属の上司が聞くときは、メモに「聞き手＝評価者」と書く。

**必要な準備**（目標2分）：本人の直近1〜2週間の記録（日報、伝票、修正履歴、写真、チャットなど、その仕事で残っているもの）を手元に置く。前回のメモがあれば見ておく。

**聞き手の手元カード（5分版用、3行）**

```
□ 最初に何をしたか → その直前に何を見ていたか
□ 「なぜ」は聞かない
□ 締めは「言葉が違うところを直してください」
```

**提示する言葉と質問**

| | 文言 |
|---|---|
| 入り | 「新しい人に渡せるものがあるかを探すために、少しだけ聞かせてください。」 |
| 問1 | 手元の記録の種類に合わせて、下の表から1つ選ぶ |
| 問2 | 「そのとき、最初に何をしました？　その直前に、何を見たり聞いたりしていました？　覚えていなければ『覚えてない』で大丈夫です。」 |
| 問3（前回のメモがあるとき） | 「前に話してくれた〇〇と同じようなことが、その後ありましたか。そのとき、同じようにしましたか、違うようにしましたか。」 |
| 締め | 「メモにはこう書きました。『〇日、△△の作業で、□□を見て、手を止めて××さんに聞いた』。言葉が違うところがあれば直してください。なければこのまま残します。」 |

**問1の入口（記録の種類ごと）**

| 手元の記録 | 問1の文言 |
|---|---|
| 日報（自由記述） | 「この2週間の日報で、途中で手を止めたり、確かめ直したり、人に聞いたりしたところを、1か所指してもらえますか。」 |
| 伝票・注文書・検査票（定型） | 「この中で、ふだんと違う選び方や書き方をした1枚はどれですか。」 |
| 修正・赤字・変更履歴 | 「ここを直したところを、1か所指してください。」 |
| 写真（作業の前後、現場） | 「この写真で、最初に目が行ったところを指してください。」 |
| チャット・メール | 「このやりとりで、聞き返したところと、返事を待たずに進めたところを、1つずつ指してください。」 |
| 予定表・工程表 | 「予定と実際が違ったところを、1か所指してください。」 |
| 記録がない | 「この2週間で、いつも通りに済んだ仕事を1つ選んでください。その仕事で、最初に確かめたことは何でしたか。」 |

「手を止めたところ」だけを聞くと、迷った判断は拾えるが、熟練者が止まらずに行う判断、先回りして問題を起こさなかった判断、やらずに済ませた判断が抜けやすい（03 の C22）。止まった場面が出やすい入口（日報）と、選択の痕跡が残る入口（定型の記録、修正履歴、写真）を、1回おきに替える。入口ごとに何が拾えて何が抜けやすいかは 05 §3-4。

問3は予測の確かめではなく、**対照の実例を集める問い**である。同じ手がかりがあったのに違うようにした実例は、抽出の材料として記録する。

**回答者の作業**：記録の1か所を指す、したことと直前に見聞きしたことを言う、メモの言葉を直す（直さなくてよい）。

**聞き手の作業**：次の4列でメモを書く。予測は書かない。仮説（ルールの形）も書かない。

| 日付 | 記録の種類と箇所 | 本人の言葉そのまま | 次に聞くきっかけ |
|---|---|---|---|
| 10/21 | 日報 10/21「B社出荷前」 | 「箱を見たら前回とラベルの位置が違ってたので、止めて事務に聞いた」 | ラベルや表記が前回と違う荷が来たとき、同じようにしたか |

（例は架空）

「次に聞くきっかけ」は、次の問3で使う。答えが「違うようにした」なら、2件の実例として並べてメモに印を付ける。1on1 のまま抽出に進むときは、30分版の確かめの問い（「もし◯◯だけが同じだったら」「もし□□だけが違っていたら」、2案、例外の問い）を、1回の1on1で1問ずつ使う。

**AI に任せられる作業**：月2件程度のメモから、聞き手が水を向けていないのに同じ手がかりが繰り返し出ているかの印付け、抽出に進めそうな実例の組（同じ手がかりで対応が違ったメモ、同じ仕事で対応が違ったメモ）の印付け、「動けなかった理由」に当たる話の抜き出し。

**出力物**：4列のメモ（1件1行）。メモそのものは**モノサシの候補にしない**。対応の違う実例がそろったら、抽出に進む（30分版でも、1on1を重ねてもよい。§0）。評価者が聞いたメモは育成（暫定）にだけ使う。メモの保存場所・閲覧者・保存期間は社内規程で決める（1on1のメモは人事評価に転用されうる個人の記録なので、社労士業務として依頼者が整えられる。10 §3 #12）。

**想定される失敗と手当て**

| 失敗 | 手当て |
|---|---|
| 「特にないです」が続く | 問1の入口を別の記録の種類に替える（定型の記録、写真など）。記録の1か所を聞き手が指すのは最後の手段（評価の目線が入るため） |
| つい「なぜ？」と聞く | 手元カードの2行目に戻る |
| 聞き手が褒め、次から部下が「役に立ちそうな話」を選んでくる | 受け答えを中立の一言に固定する |
| 部下が上司の期待する答えに寄る | 消すことはできない。「聞き手＝評価者」の記録で、出力の用途を育成に絞る |
| 毎回同じ問いで、本人が「違うこと」を探して話すようになる | 問1の入口を1回おきに替え、月2回までにする |

**次の改善方法**：2〜3か月試して、(a) 入口ごとの「特にないです」の割合と、出た手がかりが「止めた／瞬時／先回り／省略」のどれに近いか（重なってよい。分類が目的ではなく、入口ごとの取りこぼしを見るため）、(b) 抽出に進めた実例の組の数、(c) 評価者が聞いたメモと評価者でない人が聞いたメモで手がかりの具体さに差があるか、(d) 実際の所要時間、を数える（08 の試行2）。

## 2. 15分版「◎と△のやり方の違い」

**使う場面**：仕事マップのワークで、上段（段階）・中段（具体的な仕事）・担当者と◎○△まで記入した後。管理職研修では、自分の部下が担う仕事を対象にする。2人1組で、**話し手1人・書き手1人を固定する**（役を交代するなら約25分）。人事評価の時期と重なる月には行わない。

**この版で出るものは「上司の見立て」である。** 話すのは管理職で、◎の本人ではない。他人の判断についての説明は、本人の手がかりより、上司が持つ熟達のイメージになりやすい（03 の C1）。出力はモノサシの候補に入れず、◎の本人に確かめる対象を選ぶために使う。

**必要な準備**
- **経営者との事前打合せ（別途20分）**：「今年いちばん止まると困る段階」を決め、マップの上段に太枠で囲む。人による差が大きい判断ではなく、経営への影響が大きい判断から選ぶため（through-line 06段の「制約に効く判断の場面を1つ選ぶ」と同じ考え方）。
- **講師の準備（15分）**：付箋3色（黄＝したこと、青＝止まる・聞く場面、白＝違いの種類）、「上司の見立て」と書いた枠シール。

**冒頭の一言（講師）**：
「◎○△は人の点数ではありません。今日は、◎の人と△の人で、やり方がどこで違うかを見ます。その違いが、見ているものの違いなのか、届いている情報や任されている範囲の違いなのかも、一緒に見ます。今日出るのは皆さんの見立てで、正解ではありません。」

**指示と問い**

| 手順 | 時間 | 文言 |
|---|---|---|
| 1 個人 | 2分 | 「太枠の中の仕事で、◎の人と△の人のやり方が違うと感じる仕事に、★を1つつけてください。」 |
| 2 ペア | 5分 | 書き手が聞く：「その仕事の最近の1回で、◎の人と△の人が、それぞれ何をしたかを、した順に教えてください。分からないところは『分からない』で大丈夫です。」→ 書き手が黄の付箋に書く。端に「直接見た」か「たぶん」かを書く |
| 3 ペア | 3分 | 「△の人がやるとき、どこで手が止まったり、人に聞いたりしていますか。それ自体は悪いことではありません。」→ 青の付箋 |
| 4 ペア | 2分 | 白の付箋に、次のどれに近いか1つ○をつける：「見ているところが違う／届いている情報が違う／任されている範囲が違う／やったことのある回数が違う／分からない」 |
| 5 個人 | 3分 | 黄の付箋を下段の「上司の見立て」の枠に貼る。「この付箋のうち、来週、◎の人本人に1つだけ確かめるならどれですか。★をつけてください。」 |

**回答者（話し手の管理職）の作業**：★をつける、最近の1回のやり方を順に話す、違いの種類に○をつける、確かめる1枚を選ぶ。

**書き手の作業**：付箋に書く。抽象語（丁寧に、しっかり、気をつける）が出たら「その日、◎の人がしたことを1つだけ言うと何ですか」で行動に戻す。ルールの形（〇〇のときは）は書かない。

**AI に任せられる作業**：マップと付箋の写真からの文字起こし、抽象語への印、「直接見た／たぶん」の比率、白の付箋の集計（会社全体で「情報が違う」「範囲が違う」が多い段階の一覧＝仕組み側の課題の候補）、Practice Lens の同じ観点のカードとの照合（講師の裏方。紙には載せない）。

**出力物**：「上司の見立て」の枠に付箋が貼られた仕事マップ（モノサシの候補には入れない）。◎の本人に確かめる1枚（翌週の5分版か、30分版の対象選びに使う）。白の付箋の集計は、統制深度・4点セット・受け渡しの見直しの材料として経営者へ返す。

**想定される失敗と手当て**

| 失敗 | 手当て |
|---|---|
| ◎の人が同じ研修に参加していて、名指しの場になる | ◎の本人がいる組は作らない |
| 付箋がほぼすべて「たぶん」になる | それ自体が情報（上司は◎の人の仕事を見ていない）として記録し、5分版の対象選びに回す |
| 「報連相」「確認」など全員がやることが出る | 「◎の人だけがしていること」に絞り直す（Practice Lens rubric 4） |
| 時間不足 | 削るなら手順3。手順4は仕組み側への出口なので残す |

**次の改善方法**：研修後1か月で、★をつけた1枚が◎の本人の確認でどうなったか（同じだった／違った／確かめられなかった）を数える（08 の試行5）。

## 3. 30分版「記録を見て、2件を比べる」

**使う場面**：特定の人しかできない仕事、判断が難しい仕事。育休・退職・異動の引き継ぎ前。面談者（Grow3 または社内の人事担当）と本人の1対1。責任者は同席しない。主に抽出の段に使うが、対応の違う実例がそろわなければ発見で止める（§0）。

**v0.2 との関係**：すり合わせシート v0.2 の後に行う**追加の手順**で、v0.2 本体は変えない。ただし既存の06段には「1回の聞き取りは1件の案件」という禁止がある。この版は2件を扱うので、**v0.2 の聞き取り（monosashi_interview）とは別の回として記録する**（10 §3 #15 で、06段の禁止の扱いを判断待ち）。

**時間の目標**：面談の前30分＋面談30分＋面談の後30分。

**面談の前（面談者、30分）**

1. **判断点の振り分け（10分、責任者に電話で聞く程度）**
   - 「この判断は、月に何回くらいありますか。」
   - 「うまくいったかどうかは、いつ、何で分かりますか。」
   - 「失敗すると、何が起きますか。」
   - 安全・法令・金銭なら統制深度①として手順で扱い、この版の対象にしない。結果が遅い・まれな判断なら、観察ポイントは採るが、選択ルールは熟練者から写さず責任者に回すと決めておく（05 §4）。
2. **本人への依頼（1週間前、紙1枚）**：「この仕事の最近の記録（伝票・図面・写真・日報・メールなど）を、うまくいったかどうかに関係なく3〜4件、面談の3日前までに写真で送ってください。話す内容を考えてくる必要はありません。」
3. **記録を見て下ごしらえ（20分）**：同じ仕事・同じ段階で、(a) 手がかりがあって対応を変えた件と、(b) 手がかりがあったのに対応を変えなかった件、または手がかりがなかった件、の組を選ぶ。手がかりがまだ分からないときは、やり方が違っていそうな2件を選び、面談で違いを指してもらう。本人が触れないかもしれない条件□□（担当者、曜日、数量など）を記録から拾う。AI の下書きを使ってよい。
4. **手元**：仕事マップの該当行、v0.2 シート、付箋、予測を書く紙（本人に見せない）、評価表・目標設定表（面談後の照合用）。録音は本人の同意がある場合のみ。

**面談（30分）**

| 時間 | やること | 文言 |
|---|---|---|
| 0〜2分 | 導入 | 「今日は〇〇さんのやり方の正解を決める場ではありません。記録を見ながら、そのとき何をしたかを順に教えてください。うまく説明しなくて大丈夫です。新しい人に渡せるものがあるかを、一緒に探します。」 |
| 2〜13分 | 1件目を丁寧に（1件ずつ、並べない） | 「この記録の中で、手を止めたり確かめたりしたところはありますか。なければ『ない』で大丈夫です。」→「その前に、何を見たり聞いたりしていましたか。覚えていなければ大丈夫です。」→「その時点で、この後どうなりそうだと思っていたことはありますか。思い出せなければ大丈夫です。」→「それで、何をしましたか。」 |
| 13〜16分 | 2件目は1問 | 「こちらの記録に、その場面に当たるところはありますか。あれば、そこで何をしましたか。」 |
| 16〜18分 | ここで初めて並べる | 「2つを見て、違うところを指してください。」（何を違いとするかは本人に任せる。この段で新しく出た違いは、付箋の色を変えて記録する） |
| 18〜24分 | 確かめ（面談者は先に紙に「◯◯なら変わる、□□なら変わらないはず」と書く） | 「もし記録2のときに、◯◯だけが記録1と同じだったら、どちらのやり方にしたと思いますか。記録1のやり方ですか、記録2のやり方ですか、分かりませんか。」→「もし□□だけが違っていたら、どうですか。」（同じ3択）→「記録1で〇〇をしていなかったら、次の工程やお客様のところで変わったことはありそうですか。分からなければ『分からない』で大丈夫です。」（答えは「本人の見込み」として記録する） |
| 24〜28分 | 2案と例外（K1） | 「どちらでもない、でも大丈夫です。A『〇〇が分からないときは、△△する』と、B『◇◇が分からないときは、△△する』では、どちらが近いですか。」→「これを新しい人がこのとおりにやったら、困るのはどんなときですか。」 |
| 28〜30分 | 次の1回 | 「次にこの仕事があったとき、1つだけ確かめるとしたら、どの記録のどこですか。」（v0.2⑥） |

◯◯は本人が指した違い、□□は本人が触れなかった条件で、対照として聞く。□□でも「変わる」と答えたら、◯◯という説明は弱いと記録する。
「もし」への答えは、本人が仮の場面で述べた選択であり、実際の行動ではない。抽出の材料として記録し、仮説の確かめは次の実案件（K2）で行う。◯◯で「変わる」、□□で「変わらない」と答えても、記録に表れていない別の条件で対応が変わっていた可能性は残る。
2案は、**どちらも本人の言葉を使い、違いを1つの要素だけにする**（例：「サイズ」と「好み」）。一方を本人の言葉、もう一方を既に否定された条件にすると、念押しになる。両方に「近い」と答えたら、この確認には情報がないと記録し、次の実案件の予測（K2）に任せる。時間が足りないときは、2案は次の5分版で1問として聞いてよい。

**回答者の作業**：記録を送る、指さす、したことを順に話す、3択で答える、2案から近い方を選ぶ（どちらでもないでもよい）、新しい人が困るときを言う、次に確かめる箇所を指す。

**面談の後（面談者、30分）**
- 手がかりのうち、当時の記録（書き込み、撮影・送信の時刻）で行動より前にあったと確かめられるものだけを「そのときの手がかり」とし、他は「本人の振り返り」として残す（K6）。
- 「新しい人が困るとき」の答えを、例外の条件に入れる（K1）。
- モノサシ3分類へ暫定で当てはめる。「本人の見込み」が遠い（「いつか信頼が」）ものは、熟練者から写さず、選択ルールの候補として責任者に回す。
- 評価表・目標設定表と仮説を書類で突き合わせ、責任者に1問だけ聞く（K3）：「このやり方どおりにすると、今の評価表のどの項目で点が下がりますか。」
- 「動けなかった理由」に当たる話は、カード（05 §6）で記録する。
- 次の実案件の前に、§0 の K2 の手順で、場面の定義・仮説による予測・いつも通りの予測を書く。判定は面談者以外の人（責任者、または記録）が行う。

**AI に任せられる作業**：文字起こし、時系列カードの下書き（v0.2 の流れ：事実→着目点→解釈→先読み→判断→行動。本人に分類させない）、2件の差分表、□□の候補、競合する仮説2〜3案、責任者に渡す1枚の下書き。**任せないもの**：事前の予測、どの仮説を採るか、本人への返し方、認定。

**出力物**
- 本人の言葉（「そのとき」と「本人の振り返り」の区別つき）、本人の見込み
- 面談者の仮説（2〜3案、どれが残ったか、面談中の事前予測どおりだったか、例外の条件）と、まだ否定できていない別の説明（ほかの条件で対応が変わった可能性）
- 責任者に渡す1枚：本人の見え、残った仮説、本人の見込みが遠い判断、◎の人どうしでやり方が違い両方とも結果を出している場合はその両方（どちらを会社の型にするかは責任者が決める）、評価表との照合の結果
- 仕組み側の課題メモ、次の1回の確認事項（`monosashi_trial`）
- モノサシ台帳への記録：K1〜K3 を済ませたものを状態「候補」で載せる。`source_case_count` には実案件だけを数える。予測の当たり外れ・文の作り手・例外の条件は `extensions.through_line` に書く（**変更案**。10 §3 #3・#16）

**想定される失敗と手当て**

| 失敗 | 手当て |
|---|---|
| 1件目の再現が13分で終わらない | 2件目の問いと2案を削り、2案は次の5分版へ回す。18〜24分の確かめは削らない |
| 本人が記録を送ってこない | 仕事マップの「実際の出来事」欄か、面談者が事前に集めた手直し記録で代える |
| 「特に変えてない、いつも通り」と言う | 2件目に進まず、記録の書き込みのある欄を指して「ここを書いたときのことを教えてください」に戻る |
| 手こずった件の話が他人のせいになる | 「そのとき〇〇さんがしたことは何でしたか」に戻す |
| 本人が「試されている」と感じる | 予測の紙は見せない。最後に「どう使うかは責任者と相談して、使う前にお伝えします」と伝える（エージェントCの案。06段の「認定するなら理由も本人へ伝える」に沿う形） |
| 2件が別の仕事・別の工程で比べられない | 依頼の紙に「同じ仕事の、同じ段階の記録」と書く |

**次の改善方法**：3〜5件試して、実際の所要時間（前・中・後）、□□で「変わらない」が出た割合、2案の選び分けができた割合、K2 の結果（情報のある予測の当たり外れ、判定不能の数）を記録する（08 の試行1）。

## 4. 3つの版の位置づけ

版は場の違い（誰が、どれだけの時間で聞くか）で、段（発見・抽出・確かめ）とは固定しない。下の「主に使う段」は目安である。

| | 5分版 | 15分版 | 30分版 |
|---|---|---|---|
| 誰が聞くか | 管理職・先輩 | 研修のペア（講師が進行） | 面談者（Grow3・人事担当） |
| 誰の判断か | 本人 | ◎の人（上司の見立てとして） | 本人 |
| 主に使う段 | 発見。重ねて対応の違う実例がそろえば抽出にも | 発見（上司の見立て） | 抽出。実例がそろわなければ発見で止める |
| 出るもの | 1件の出来事のメモ、次に聞くきっかけ、対照の実例 | 確かめる対象の候補、仕組み側の課題の集計 | 仮説2〜3案と別の説明、例外の条件、責任者に渡す1枚 |
| モノサシの候補にするか | どの版で出たものも、K1〜K3 を済ませるまでは候補にしない | 同左 | 同左 |
| つながり | 抽出の材料（対照の実例）、K4 の結果の回収 | 5分版・30分版の対象選び | モノサシ台帳、07段の用途の仕分け |

身体に埋め込まれた技能（移乗、溶接、包丁さばきなど）は、どの版でも取り出せない。観察と共有経験（同行・実演・やってみせる）で移す（暗黙知の第3類型）。
