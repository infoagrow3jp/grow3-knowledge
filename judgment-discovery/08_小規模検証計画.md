# H. 小規模検証計画

作成：2026-10-25　状態：計画案（未実施）

## 1. 結論

最初の試行は**1社・1判断点・2か月**で行う。確かめたいことは、最重要の評価基準をそのまま測れる形にした次の3つに絞る。

1. **負担**：判断基準を説明できない人が、現行の直接質問より軽い負担で参加できるか
2. **手がかり**：出てきた手がかりから立てた判断仮説を、支持する証拠と弱める証拠が集まるか（事前に書いた予測の当たり外れは、その証拠の一つ。当たりは証明ではない）
3. **他の人への効き目**：その手がかりを暫定で渡した人が、実際の場面で使えたか

判定線（どの結果なら方法を直すか）は、**根拠のある数値ではなく、最初の試行のために置いた暫定の目安**である。1回目の結果を見て置き直す。

## 2. 試行の前に決めること

| 項目 | 決めること | 誰が |

| 判断点 | 1つ。05 §4 の振り分けの3問を責任者に聞き、統制深度①（法令・安全・金銭）ではないもの。経営への影響が大きい段階から選ぶ | 小林さんと責任者 |

## 3. 試行の内容

### 試行1：30分版（主試行）

- **対象**：同じ判断点を担う熟練者1〜2人。1人あたり2回（2回目は別の記録で）。合計3〜4件。
- **比較の基準**：同じ人に、30分版の後の**別の日に**、現行の直接質問を1問だけ行う（「この仕事で、何を見て判断していますか。3つ書いてください」。モノサシ言語化シートの4観点に近い形）。これと30分版の出力を比べる。
- **測ること**

| 指標 | 測り方 |
|---|---|
| 所要時間 | 面談の実測（分）。準備時間も別に測る |
| 本人の負担感 | 後日、面談者以外の人が1問：「この前の話は、話しやすかったですか」（話しやすかった／普通／話しにくかった）。あわせて「覚えてない／分からない」の回数、所要時間、次の回に実際に協力してくれたか |
| 具体的な手がかりの数 | 出た手がかりのうち、Practice Lens rubric の2・3・5（抽象語で終わらない／判断の動詞で終わる／1つの場面）を満たすものの数。直接質問の出力と比べる |
| 「そのとき」の比率 | 手がかりのうち、当時の記録で行動より前にあったと確かめられたものの割合 |
| 事前予測の的中（面談の中） | 対照の問いで、◯◯では変わり□□では変わらない、という予測どおりになったか |
| 2案の選び分け | 競合する2案のうち一方を選べたか（両方「近い」は情報なし） |
| 例外の条件 | 「新しい人が困るとき」で例外が出たか |
| 次の実案件での予測（K2） | 06 §0 の K2 の手順で。情報のある予測（仮説といつも通りで予測が違う回）の当たり／外れ、いつも通りと同じ予測になった回、判定不能、外れの読み（重なってよい） |
| 書類照合（K3） | 評価表・目標設定表とぶつかったか |

### 試行2：5分版（日常版）

- **対象**：管理職2名が、それぞれ部下2名に、2か月間、月2回（合計16回程度）。うち1名の管理職は直属の評価者、もう1名は評価者でない立場の人にできると比べやすい。
- **入口の比較**：問1の入口を、止まった場面が出やすい入口（日報）と、選択の痕跡が残る入口（定型の記録、修正履歴、写真など、その仕事で残っているもの）の2種類以上で1回おきに替える（05 §3-4）。出た手がかりごとに「止めた／瞬時／先回り／省略」のどれに近いかを書く。重なってよく、分けること自体は目的ではない。入口ごとに何が抜けているかを見るために使う。
- **測ること**：実施できた回数、1回の所要時間、入口ごとの「特にないです」の割合、入口ごとの手がかりの見え方の内訳、抽出に進めた実例の組（同じ手がかりで対応が違った、同じ仕事で対応が違った）の数、抽出に進んだ後に仮説として残った手がかりがどの入口から出たか、評価者が聞いた場合とそうでない場合の手がかりの具体さ（rubric 2・3・5を満たす数）。

### 試行3：並べるか、1件ずつか（対立①の検証）

- 試行1の中で行う。手がかりごとに、**1件ずつの再現の段で出たか、並べた段で新しく出たか**を記録しておく（30分版は付箋の色を変える手順になっている）。
- **見ること**：並べた段で新しく出た手がかりが、次の実案件での予測にどれだけ使われ、当たったか。並べた段の手がかりが外れやすければエージェントDの懸念が、同じくらい当たればエージェントA・Cの見方が支持される。件数が少ないので、傾向を見るだけにする。

### 試行4：他の人に役立つか（K4）

- 試行1で残った候補のうち1〜2個を、△の人に**暫定**として渡す（07段のとおり、守るべき決まりとしては伝えない）。
- 次の5分版で聞く：「先週伝えた『〇〇のときは△△』、使う場面はありましたか。使ってみてどうでした。」（使えた／場面がなかった／使えなかった）
- 手直し・問い合わせ・相談の記録がある会社では、その場面で手直しや相談の要否が適切だったかも、責任者が記録で見る（「熟練者に似たか」ではなく、後で出る結果で見る。対立②）。

### 試行5（任意）：15分版

- 管理職研修で行う機会があれば実施する。研修後1か月で、★をつけた付箋が◎の本人の確認で「同じだった／違った／確かめられなかった」を数える。上司の見立てと本人の言葉の一致の程度を見る。

## 4. どの結果なら方法を直すか（暫定の判定線）

| 結果 | 判定線（暫定） | 直すところ |
|---|---|---|
| 30分版が長すぎる | 実測で45分を超える件が半分以上 | 2件目の問いと「新しい人」の問いを削る。準備の記録選びを面談前に済ませる |
| 本人の負担感が直接質問より重い | 「話しにくかった」が直接質問より多い | 方法そのものを見直す（最重要の評価基準に反する）。どの段で詰まったかを聞き、その段を外す |
| 具体的な手がかりが直接質問より増えない | rubric 2・3・5 を満たす数が直接質問以下 | 記録の選び方（やり方の違う2件が選べているか）と、問いの文言を見直す |
| 対照の条件でも「変わる」が多い | □□でも「変わる」が半分以上 | 2件の選び方か、◯◯の拾い方が誘導的になっていないかを見る |
| 2案の選び分けができない | 両方「近い」が半分以上 | 2案の作り方を変える（AI の下書きに頼りすぎていないか） |
| 情報のある予測が当たらない | 抽出に進んだ件を合わせて、情報のある予測の最初の5件で当たりが2件以下（判定不能は除く） | 外れの読み（場面の定義のずれ／別の条件／やり方の変化／記録不足）を見て、場面の定義か仮説を直す。別の条件で変わっていたなら抽出に戻す |
| 予測がいつも通りと同じになる | 書いた予測の半分以上で、仮説による予測といつも通りの予測が同じ | 判断点の選び方を見直す（いつも同じ対応になる仕事では、予測で確かめられない） |
| 入口による取りこぼしが大きい | どの入口でも「止めた」に近い手がかりしか出ない | 選択の痕跡が残る記録からの入口を増やす。記録がない仕事は同行・観察に切り替える |
| 5分版が続かない | 「特にないです」が半分以上、または予定の半分も実施できない | 問1の文言を替える。頻度を下げる |
| 評価者が聞くと手がかりが薄い | 評価者のメモで rubric を満たす数が明らかに少ない | 5分版の聞き手を評価者でない人にする運用を標準にする |
| 渡した手がかりが使えない | 「使えなかった」が「使えた」より多い | 手がかりの粒度（場面が広すぎないか）と、渡し方を見直す |
| 書類照合でぶつかりが多い | 候補の半分以上が評価・目標とぶつかる | モノサシ化より先に、評価制度と目標の置き方の話を経営と行う（人事制度設計OS へ） |

判定線を超えなくても、気になることがあれば記録する。超えたからといって方法を捨てるのではなく、どこを直すかの合図として使う。

| 方法の手直し（問いの文言、時間配分） | この作業フォルダの 06 の改訂（変更履歴に理由と結果を書く） |
| 主張の根拠区分の変化（例：C2 が業務記録でも成り立つか、C10 の是非） | 03 の改訂（変更履歴に理由と根拠を書く） |
| 業種を超えて効いた問い | 打合せの Evidence に起こし、Structurer が Lens 候補として `record_kind: origin` で紐付ける（`practice-lens/framework/reuse_map.md` の還流の手順1〜3）。3択・2択の問いは rubric 9 に外れるので、自由回答の形に直してから出す |
| 既存資産（v0.2、仕事マップ、07段など）の変更が必要と分かったこと | 10 の変更案一覧に追記し、小林さんの判断を待つ |

## 6. この計画の限界

- 1社・数件では、方法の効果を示すことはできない。分かるのは、手順が回るか、どこで詰まるか、明らかにおかしいところがないか、までである。
- 熟練者に近づいたか、後で出る結果がよくなったか（対立②）は、件数と時間が要る。複数の顧問先で同じ型の判断点を集めるのは、この計画の後の段階になる。
- 予測の当たり外れは判断仮説の証拠の一つにすぎない。当たりが続いても仮説の証明にはならず、組織として望ましいかも分からない（望ましさは K3、責任者の決定、後で出る結果で見る）。
- 入口の比較は少数で傾向を見るだけで、どの入口がよいかを決めることはできない。
- 面談者が小林さん1人である限り、「別の聞き手でも同じものが出るか」（再現性）は測れない。社内の人事担当か管理職が30分版を行う回を、2回目以降に入れることを検討する。
