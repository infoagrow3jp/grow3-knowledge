# 【テスト素材・架空】前回確定した設計の決定記録

※eval用の架空素材です。会社・人物はすべて架空で、実案件ではありません。

株式会社ミナトヤマ精機（架空）向け 半日研修の決定記録（確定済み・最新版）

## 確定時の前提
- 対象：入社3〜5年目の製造・検査の社員 12名（班長候補）
- 実施：半日（3時間）

## 決定事項

| No | 項目 | 決定内容 |
|---|---|---|
| D1 | 研修名 | 「次世代の班長を育てる 班長候補研修」 |
| D2 | 研修ゴール | 研修後、自分が受け持つ後輩との月1回の1on1を、問いの順番を決めて進められる |
| D3 | スライドの時間表記 | スライドには、ワークの制限時間以外の時間（開始・終了時刻、パート全体の所要時間）を書かない |
| D4 | 配布物の名称 | 持ち帰り用の紙は「持ち帰りシート」とし、A4一枚にまとめる |
| D5 | ワークの教材 | 後輩から「特にありません」と返されたときの対応場面を題材にした、班長役・後輩役のやり取り |
| D6 | 事前アンケート | 研修の1週間前に、参加者へ3問のアンケートを実施し、結果を講師の手元資料に反映する |
