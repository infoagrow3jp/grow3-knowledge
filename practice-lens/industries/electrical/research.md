# 電気工事 業種調査

調査日：2026-10-10
担当：Researcher（業種調査役）
出力の位置づけ：カード化前の生の材料。出典のない記述は書いていない。

**前提：「電気工事業」の職業能力評価基準は存在しない。** 本調査は、電気通信工事業（E系）と総合工事業（G系）の基準を組み合わせ、どちらから何を拾ったかを出典略号で分けている。電気工事そのものの一次資料としては、JOB tag（J系）、電気工事士技能試験の欠陥判断基準（K系）、電気工事業法の立入検査結果（M2）、労働災害事例（A系）を使った。

## A. 価値の流れ（業種固有の工程名）

共通語彙：intake / survey / design / production / handoff / install / close / after / support
型：project_based / repetitive_production / store_retail / human_service / professional_service

職種の枠組み：
- 電気通信工事業（E1・E3）：営業／施工管理／施工技能（現場管理、施工技能）の3職種4職務。E3 は「営業、施工管理、現場管理、施工技能の3職種（4職務）」と表記。
- 総合工事業（G1）：建設営業（建設営業部門運営／建設営業実務／建設営業事務）／建設生産管理（建設生産部門運営／現場生産管理／建設生産システム管理）の2職種6職務。想定企業は完工高30〜50億円程度の地場建設会社（元請）。
- 電気工事士の仕事（J1「どんな仕事」）：建物内で電線を配線し、電気を利用するための設備を設置する。変電設備、幹線、分電盤、配線、コンセントや照明器具の取付け。通常2〜4人のグループで、図面に基づいて作業し、作業後は試験を行い試験成績書を作成する。

### 型が変わる境目（一社の中で）

- **境目1（重点①）：工程8 盤の設計・製作（production）→ 工程11 現場施工（install）。** 根拠は J2 タスク3 と M1 別表の「機器製作」のみ。電気通信工事業の基準（E1）には製作ユニットが無く、製作と施工を同じ会社が持つ場合の分業は資料に書かれていない。
- **境目2（重点②）：工程9 元請→協力業者（下請）。** G1 が元請（地場建設会社）を想定し、現場側「購買管理」と部門側「協力業者指導」「部門購買」を分けている。J3 では下請の選定・工事費・工期の調整（94.9%）、相番の日程調整（97.4%）、工程変更に伴う下請との折衝（89.7%）がタスクとして独立している。M2 では請負に出した工事でも帳簿に実際の作業者氏名を書く義務がある。
- **境目3（重点③）：工程11〜13 施工（install）→ 工程15〜16 試験・検査・引き渡し（close）。** E1 では「検査・引き渡し」が施工管理職種の独立ユニット。J1 では試験（87.2%）と試験成績書（80.9%）が器具取付・配線（89.4%）と別タスク。M2 では主任電気工事士が検査結果を確認する。K1 の欠陥判断基準は試験における「欠陥」の線。
- 境目4：工程16 引き渡し → 工程19〜20 アフターメンテナンス・保守。E1 では「アフターメンテナンス」が施工管理職種、「保守・運用管理」が現場管理職務、「保守・運用」が施工技能職務に、それぞれ別ユニットとして置かれている（3職務に分散）。
- 境目5：工程6 設計 → 工程7 施工計画。総合工事業（G1）では「設計」「積算」「技術提供」が建設営業実務（営業職種）側にあり、施工計画は建設生産管理側にある。J3 タスク15「設計の意図や不明点を確認するため、設計者と打ち合わせする」（97.4%）が、この境目で起きる確認の仕事。

### 境目が無い場合もある

- J1 就業ルート：大企業では15〜20年の経験を経て職長になるケースがあり、電気主任技術者などの資格を取って管理職や独立開業へ進む人もいる（小規模での一人完結を直接述べた記述は無い）。
- J1「どんな仕事」：作業は通常2〜4人のグループで行う。
- E2 営業L2「自社の施工力を顧客に伝える」：営業と施工が同じ会社の中にあることを前提にした記述。

## B. 判断が分かれるところ（候補）

※K：K1 は一次資料未読の転載ページ。項目番号は転載の表記に従う。

### B-1 見積前に現地で何を見て、仕様書に何を書くか

## C. 型の境目で起きること

### 境目1：盤の設計・製作（production）→ 現場施工（install）

- 資料にある事実：J2（製造業の電気技術者）のタスクに「自動制御盤の設計や製作」がある。M1 の段階確認一覧表では「機器製作」が、耐震施工・配管・配線・接地などの現場項目と並ぶ独立の確認項目である。
- 前工程の「完了」：M1 では機器製作が段階確認を受けることで次に進む（公共工事）。
- 後工程の「完了」：J1 では据付け・配線の後、試験を行い試験成績書を作成する。
- 何が渡されるか：**資料に書かれていない。** 製作側から施工側へ渡される図面・結線図・試験記録の有無や形式は、E1・G1・J1・J2 のいずれにも記述が無い。電気通信工事業の基準に製作ユニットが無いため、同一社内で製作と施工を両方持つ場合の分担は本調査の範囲では裏づけられない。

### 境目2：元請 → 協力業者（下請）

- 資料にある事実：G1（総合工事業）は元請を想定し、下請に関わるユニットを現場側「購買管理」と部門側「協力業者指導」「部門購買」の2層に分けている。J3 では下請の選定・工事費・工期の調整（94.9%）、相番の日程調整（97.4%）、変更に伴う下請との折衝（89.7%）、元請として客先と交渉（97.4%）がタスクとして独立している。M2 では請負に出した工事でも帳簿に実際の作業者氏名を記載し、無資格業者への請負は禁止（第22条）。M1 では監督職員が施工体制（施工体制台帳、下請を含む）を把握する。
- 前工程（元請）の「完了」：J3 の記述では、客先との交渉、下請の選定と工期・工事費の調整、相番の日程調整。
- 後工程（下請）の「完了」：J1 の記述では、仕様書に従った据付・配線と、試験・試験成績書。
- 何が渡されるか：J3 タスク1「施工図を基に…施工計画を立てる」、J1「図面に基づいて進めます」から、図面（施工図・仕様書）が渡されることは読める。工期・工事費は元請が「調整する」（J3）。
- 何が渡されないか（資料から読めるもの）：A1 の災害では、複数の組織が混在する現場で「指揮命令系統が不明確」だったことが原因の一つとされ、対策として「作業範囲、作業時間、停電時間を明確にする」が挙がっている。つまり、作業範囲・作業時間・停電時間は、明示的に決めなければ渡されない。
- 責任の線：M2 の帳簿義務により、下請に出しても元請側の帳簿に作業者氏名が残る。E2 施工管理L4「施工部門や協力業者などの調整」が、下請調整をL4（部門統括）の仕事として置いている。

### 境目3：施工（install）→ 試験・検査・引き渡し（close）

- 資料にある事実：E1 では「検査・引き渡し」が施工管理職種の独立ユニット（施工技能職種側には無い）。J1 では試験（87.2%）・試験成績書（80.9%）・完成図提出（74.5%）が、器具取付・配線（89.4%）と別タスク。M2 では工事完了後の検査結果を主任電気工事士が確認する。M1 では完成・既済・完済・中間技術の検査があり、契約図書に適合しない場合は改造請求・破壊確認がある。
- 前工程（施工）の「完了」：J1 では「仕様書に従い」据付・配線が終わった状態。
- 後工程（検査）の「完了」：J1 では試験装置で回路の連続性などを試験し、試験成績書を作る。M2 では絶縁抵抗計・接地抵抗計・回路計等の検査器具が営業所に備わっていることが前提。
- 品質の線：K1 の欠陥判断基準は、試験における「欠陥」を項目ごとに（多くは数値で）定義し、「一つでも該当すれば不合格」としている。配線図・施工条件との不一致、色別・極性、心線露出のmm、リングスリーブの選択・マーク、器具への結線、金属管・可とう管の接続、取付枠、支給品以外の使用、不要な工事、器具の破損。**現場の引渡し検査にこの基準がそのまま使われるかは資料に無い。** ただし K1 の線は電気工事士が入職前に通る線であり、施工側と検査側が共有している唯一の明文の線として位置づけられる（この一文は本調査の整理であり、資料の記述ではない）。
- 何が渡されるか：J1 では試験成績書と完成図。M2 では帳簿への記載。
- 何が渡されないか：M1 の「確認」と「把握」の区別のように、見た（把握）だけで認めた（確認）ことにならない線を民間工事でどう置くかは資料に無い。

### 境目4：引き渡し → アフターメンテナンス・保守

- 資料にある事実：E1 では「アフターメンテナンス」（施工管理職種）、「保守・運用管理」（現場管理職務）、「保守・運用」（施工技能職務）が、3つの職務に別ユニットとして置かれている。G1 では「リフォーム及びアフターサービス」が建設生産部門運営（部門側）にある。
- 前後で変わるもの：J2 では保守側の仕事が「不具合の原因を調査」（88.9%）、「施設補修や故障対応」（83.3%）、「予防保全の提案」（63.0%）、「老朽化設備のリニューアル」（68.5%）に分かれ、調査・対応は高く、提案は低い。
- 何が渡されるか：資料に明記なし。J1 の完成図・試験成績書が引渡し時の成果物であることまで。

### 境目5：設計 → 施工計画

- 資料にある事実：G1 では「設計」「積算」「技術提供」が建設営業実務（営業職種）に、「施工計画」に当たる仕事は建設生産管理側にある。J3 では「設計の意図や不明点を確認するため、設計者と打ち合わせする」（97.4%）が施工管理のタスクとして独立している。J3 の説明では、設計は建築設計者が担当する。
- 何が渡されないか：J3 の「設計の意図や不明点」の確認がほぼ全員のタスクであることから、図面だけでは意図が渡らないことが読める。

## D. この業種にしかないもの／他業種にもありそうなもの

根拠は要らない段階。照合役が後で判定する。

### 電気工事に固有と思われるもの

- B-2 停電作業か活線作業か（電気の有無が作業の前提条件になる）
- B-3 「電源を切った」とみなす範囲（スイッチ／盤内ブレーカー／元電源）
- B-4 作業前の検電
- B-7〜B-10 欠陥判断基準の線（配線図との一致、寸法・心線露出のmm、色別・極性、リングスリーブ）
- B-11 主任電気工事士による検査結果の確認と検査器具（電気工事業法に固有）
- B-16 帳簿（請負に出した工事の作業者氏名）と標識（電気工事業法に固有）

### 他業種にも同じ構造がありそうなもの

- B-1 見積前の現地調査で何を見るか（看板業の現地調査と同型）
- B-5 工具・保護具の選択（建設系全般）
- B-6 複数組織が混在する現場の指揮命令系統（元請・下請のある建設系全般、施設内作業全般）
- B-12 隠れる前の段階確認（建設系全般。「確認」と「把握」の区別は公共工事の監督一般）
- B-13 適合しないものを作り直すか壊して確かめるか（建設・製造全般）
- B-14 変更をいつ見積に出し、下請とどう折衝するか（元請・下請のある業種全般）
- B-15 アクシデント対処と再発防止（全業種）
- B-17 段取りを経験で組む（建設・製造全般）
- B-18 修理で済ませるか予防保全を提案するか（設備保守のある業種全般）
- B-19 自社の施工力を営業が伝える（営業と製作・施工が分かれる業種全般）

### 境目について

- 境目1（製作→施工）は看板業の「製作→施工・設置」と同型に見えるが、電気工事では製作ユニットが基準に無く、資料の裏づけが薄い。
- 境目2（元請→下請）は総合工事業の基準が最も厚く、建設系の横断構造。電気工事固有なのは帳簿・無資格請負禁止の法的な線のみ。
- 境目3（施工→検査）は、試験の欠陥判断基準という明文の線がある点で、看板業より線が濃い。他業種で同等の明文基準があるかは照合役に委ねる。
