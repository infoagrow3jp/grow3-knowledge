## A. 価値の流れ（業種固有の工程名）

共通語彙：intake / survey / design / production / handoff / install / close / after / support
型：project_based / repetitive_production / store_retail / human_service / professional_service

**共通語彙の当て方（調査役の判断。資料の語ではない）**：共通語彙は受注型を前提に作られているので、店舗小売では次のように読み替えた。売場に商品を用意する工程（発注〜加工〜陳列）を production、顧客に商品を渡す工程（販売・レジ）を handoff、売上金処理・棚卸・記録を close、クレーム・返品・顧客管理を after、人員・教育・設備を support とした。予約・大型注文・催事は、個別の受注があるので intake から始まる別の流れとして分けた。

### 型が変わる境目（一社の中で）

- **境目1（重点）：店舗運営（store_retail、反復）→ 予約・大型注文・催事・ギフト（project_based、個別）**。同じ店・同じ人が、片方では「売場を切らさず・余らせず回す」、もう片方では「一件ごとに受けて・見積もって・作って・渡す」。資料側の根拠は、S16 の予約販売、S8 の贈答包装（実施率72.4%で、レジ係のタスクの中で低い側）、S11 で見積り・デザインが1級にしか無いこと。
- **境目2：菓子製造（repetitive_production）→ 店頭販売（store_retail）**。S9 は職人に「販売、経営に関する知識」も求め、S10 は「生菓子は多くは当日中に売り切る」とする。製造量の決定が販売側の見込みに依存する。
- **境目3：店内加工（販売・加工）→ 売場（販売）**。S1 で職務が分かれ、加工には「技能と経験が必要」（S7）、切り傷災害の発生場所（S13）。型は同じ store_retail だが、仕事の性格が製造寄りに変わる。
- **境目4：店舗 → 本部（多店舗化）**。S1 は共通ユニットを「（店舗）」「（本部）」で二重に持ち、選択ユニットも「対外折衝（店舗）／（本部）」「店舗予算の計画と管理（店舗）／店舗予算の策定と管理（本部）」「販売促進（店舗）／（本部開発部門）／（本部企画部門）」と対で置く。S3 は「複数店舗管理」「店長代行者育成」を独立ユニットとする。S4 は L1 店長代行 → L2 初級店長（本部や先輩店長の指導を受けながら）→ L3 中級店長（標準より大きい店・特異性のある店）→ L4 上級店長（不振店の立て直し、他店長・本部・外部への影響力）。
- **境目5：売場（販売）→ レジ・売上金（チェッカー）**。S1 で職務が分かれ、「売上金の処理」はチェッカーとストアマネジメントの両方に置かれる。S7 では店員も「忙しい時のレジ応援」を行う。

### 境目が無い場合もある

- S9「多くは小規模経営」。S10「従業員が少ない中小の店が多い」。S16 の中央値は正社員14.0人・パート等48.6人（店舗規模の中央値）。小規模店では製造・販売・注文受けを同じ人が持つ可能性があるが、資料はそこまで書いていない。

## B. 判断が分かれるところ（候補）

凡例：工程番号は A の表（A-1 はスーパー、A-2 は菓子店、A-3 は個別対応）。分かれる理由は「経験差／基準の不在／情報の不足／前後工程との認識差」のどれか。

### B-1 発注数量をいくつにするか（欠品と廃棄の両側）
- 工程：A-1 工程4
- 何を見て何を決めるか：売れ行き・在庫（S6 タスク4）、天候・販売実績（S14）、リードタイム（S14）を見て、入荷数を決める（S7 タスク1）。
- なぜ分かれるか：基準の不在＋情報の不足。基準側は L1 を「上司の指示のもとで正確に発注する」と置く（S2）。つまり**数量を決める判断は L1 の基準の外にあり、誰がどう決めるかは各社に委ねられている**。欠品側のコストは資料に直接の記述が無い。廃棄側は S7 で値引き（重要度3.7）と廃棄（3.7）が店員タスクの中で上位の重要度で、S14 は「売れ残りを減らす従来の工夫に加え、発注を早期に行うこと」を求める（取引先側の廃棄を抑えるため）。
- **資料に書かれていないこと**：欠品と廃棄のどちらを避ける線の引き方。S14 が示すのは「天候や販売実績のデータで需要予測の精度を高め」「リードタイムを十分に確保」という方向だけ。
- 出典：S7 タスク1・9・12、S6 タスク4、S2 販売L1 発注・在庫管理、S14 取組1

### B-2 値引き（マークダウン）をいつ・どれだけ
- 工程：A-1 工程9
- 何を見て何を決めるか：期限の近さ・売れ残り（S7 タスク9）を見て、値引きの時期と幅を決める。
- なぜ分かれるか：基準の不在。S3 は「マークダウンの検討・実施」を独立ユニットとし、S2 は L3 に「チラシ特売の効果や重点商品の売価を分析し、販売計画に反映」を置く。L1 の売価に関する基準は S2 の抜粋には無い。
- 出典：S7 タスク9（92.3%、3.7）、S3 商品管理「マークダウンの検討・実施」「商品ロス削減」、S2 L3 例

### B-3 廃棄にするか・まだ売るか
- 工程：A-1 工程9
- 何を見て何を決めるか：賞味期限（S7 タスク12）と、自社の手順（S2「自社の手順に従い、要廃棄食品などを処理する」）。
- なぜ分かれるか：基準の不在。基準側は「自社の手順」に委ねる。外食産業の基準は「食材別のロス管理・廃棄食材の管理」を購買側のユニットに置く（S5）。
- 出典：S7 タスク12（94.2%、3.7）、S2 共通ユニット、S5 商品管理

- なぜ分かれるか：経験差。S11 で1級のみの実技。S10 タスク19「製造コストや売上を計算し、記録する」（82.0%）が反復側の原価把握に当たる。
- 出典：S11、S10 タスク19

### B-18 床の水濡れ・放置物・機械の清掃手順（安全）
- 工程：A-1 工程6・15
- 何を見て何を決めるか：濡れた床を拭くか放置するか、機械を止めてから清掃するか。
- なぜ分かれるか：基準の不在（作業手順が不明確）。S12 事例1（挽肉機械）：機械を止めずに清掃、破損した電源スイッチを放置、「作業手順が不明確」。事例2（惣菜売場の転倒）：水濡れの未拭取り、マット未設置。小売業の災害は転倒34%、腰痛等13%で約半数（S12）、別統計で転倒45.1%（S13）。経験3年未満が商業の災害の44%（S12）。
- 出典：S12、S13

### B-19 店舗の権限はどこまでか（仕入れの仕組みを変えてよいか）
- 工程：A-1 工程4・16（横断）
- 何を見て何を決めるか：店舗で改善してよい範囲と、本部の権限の範囲。
- なぜ分かれるか：基準の不在（各社の権限設計）。S2 のカスタマイズ例は、L3 の「仕入れシステムの改善」を「商品部長（レベル4）の権限に属するため削除」する。基準側は権限に合わせてユニットを削る前提。
- 出典：S2 カスタマイズ例、S1 仕入れ「仕入システムの改善（本部）」

### B-20 評価の目線（○△×の甘辛）
- 工程：A-1 工程14（人事評価）
- 何を見て何を決めるか：「一人でできている（○）」「ほぼ一人で（△）」「できていない（×）」の線。
- なぜ分かれるか：経験差（評価者間）。S2 は「本人と上司の評価にばらつきが大きい細目」を特定し、「評価者に“甘辛”が発生していないか確認」する目線合わせ会議を推奨。本人○・上司×の項目を「重要な育成ポイント」とする。事例では L1 は「ほぼ全ての項目が○」、L2 で「得手・不得手にムラ」。
- 出典：S2 判定基準・p.21・事例3

## C. 型の境目で起きること

### 境目1：店舗運営（反復）→ 予約・大型注文・催事・ギフト（個別）

- 前工程（反復）の「完了」：売場が切れず・余らず回り、締めが合うこと（S7 補充98.1%、S8 売上集計、S6 記録）。
- 後工程（個別）の「完了」：一件の注文が、約束した内容・日時で渡ること（資料に完了の定義は無い。S16 は「予約販売が好調」としか書かない）。
- 渡されるもの：反復側の製造・仕入の仕組み（A-3 工程4 は反復工程をそのまま使う）。
- 渡されないもの：**注文一件ごとの見積り・意匠・受け渡しの基準**。S11 で見積り・デザイン・製品検査は1級にしかなく、S8 の贈答包装は実施率が低い側。反復側の基準（S2 の L1 基準文）はいずれも「上司の指示」「決められた規格」「自社の手順」を前提に書かれていて、注文一件ごとの判断には届かない。
- 資料から言えるのは、繁忙期（S10：10月〜3月）に個別対応が反復運営の上に乗ることまで。両方を同じ人員で回すときの優先順位は資料に無い。

### 境目2：菓子製造（反復生産）→ 店頭販売（店舗小売）

- 前工程の「完了」：製品検査を通り、包装・箱詰めされること（S9 タスク13・14、どちらも実施率95%超）。
- 後工程の「完了」：当日中に売り切ること（S10「多くは当日中に売り切ります」）。
- 渡されるもの：製品。製造記録（S9 タスク15）。
- 渡されないもの：**売れ残り・売り切れの情報が翌日の製造量に戻る経路**。S10 タスク20 生産計画（重要度4.1）と S10 タスク19 コスト・売上の計算は製造側のタスクとして並ぶが、販売側の見込みをどう製造側に渡すかは資料に無い。

### 境目3：店内加工 → 売場

- 前工程の「完了」：入荷品が「店頭に出せる」形になること（S7 タスク3）。
- 後工程の「完了」：売場に並び、補充され、期限管理されること。
- 渡されるもの：加工済み商品、値札（S7 タスク5）。
- 渡されないもの：加工側の「技能と経験」（S7）は売場側に渡らない。災害は加工側（切り傷、S13；挽肉機械、S12）と売場側（転倒、S12）で型が違う。

### 境目4：店舗 → 本部（多店舗化）

- 前工程（店舗）の「完了」：店舗営業方針の「推薦」、店舗予算の「計画と管理」、販売と在庫の報告書（S1、S6 タスク14）。
- 後工程（本部）の「完了」：営業方針の「策定と管理」、店舗予算の「策定と管理」、店舗の「経営指導・監督」（S1 店舗運営SV）。
- 渡されるもの：報告（S6 タスク14・15、S7 タスク16）、本部指示（S7 タスク17）。
- 渡されないもの：**推薦と策定の間**（店舗は推薦まで、策定は本部という語の使い分け、S1）。**仕入れの仕組みの改善**（L4 商品部長の権限、S2）。店長代行の定義（S4 L1「店長不在の際は、店長代行として店舗運営・管理を行える」）と、店長代行者育成（S3）が、店長を店舗から外せるようにする前段として置かれている。
- S4 のレベル定義は「標準的な規模の店（L2）」→「標準より大きい店・特異性のある店（L3）」→「不振店の立て直し、他店長への影響力（L4）」と、**店の難しさ**でレベルを刻む。多店舗化の順序（どの店を誰に渡すか）の手がかりになる。

### 境目5：売場 → レジ・売上金

- 前工程の「完了」：値札・特売価格が売場に出ていること（S7 タスク5、S8 タスク2）。
- 後工程の「完了」：会計が合い、打ち間違い・返品が集計されること（S8 タスク14・15）。
- 渡されるもの：特売品の種類と価格（S8 タスク2、89.7%）。
- 渡されないもの：返品・苦情の処理権限の線（B-10）。「売上金の処理」がチェッカーとストアマネジメントの両方にある（S1）ので、締めの責任がどちらにあるかは各社で違う。

## D. この業種にしかないもの／他業種にもありそうなもの

根拠は書かない。照合役が後で判定する。

### 業種固有と思われるもの
- B-1 発注数量（欠品と廃棄の両側）— 日配・生鮮の当日性が前提
- B-2 値引きのタイミング
- B-3 廃棄の判断
- B-4 納品期限・販売期限（3分の1ルール）
- B-8 店内加工の量・切り方
- B-9 特売・目玉商品
- B-15 菓子店の当日製造量
- B-16 菓子店の製品検査（異物・異常）

### 他業種にも同じ構造がありそうなもの
- B-5 検品で数量だけ見るか品質も見るか（看板業の購買・外注、介護の物品にも）
- B-6 上位者の指示が3層にある中でどの層の判断が残るか
- B-7 規格どおりか目的に合わせるか
- B-10 苦情を現場で止めるか上げるか
- B-11 応援を呼ぶ線
- B-12 繁閑に合わせた配置
- B-13 何を本部（社長）に報告するか
- B-14 個別対応をどこまで受けるか（反復型の上に個別が乗る構造）
- B-17 注文品の見積り（看板業の積算・見積りと同型）
- B-18 床・機械の安全手順
- B-19 現場の権限はどこまでか
- B-20 評価の甘辛・目線合わせ

### 判断保留
- A-4 の「店長に渡す仕事の一覧」は、店舗小売固有の並びだが、「社長が持っている仕事を現場の責任者に渡す」構造そのものは多店舗化・多拠点化する業種に共通しそう。照合役の判定に委ねる。
