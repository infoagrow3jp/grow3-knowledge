## A. 価値の流れ（業種固有の工程名）

共通語彙：intake / survey / design / production / handoff / install / close / after / support
型：project_based / repetitive_production / store_retail / human_service / professional_service

職種の枠組みは S1・S3 の4職種（5職務）：企画・営業／デザイン・設計／製作・施工管理（職務：施工管理）／製作・施工（職務：製作、施工・設置）。
S3 p.16 の職務説明文：
- 企画・営業：屋外広告の企画提案をまとめ、顧客への提案や交渉などの営業活動を進める
- デザイン・設計：広告コンセプトに基づくデザインを作成し、広告物や施工に向けた設計を行う
- 製作・施工管理：品質・原価・工程（納期）を管理し、安全・衛生に配慮しながら製作・施工現場を統括する
- 製作・施工：設計図面に基づき広告物を製作し、施工・取付け・設置・メンテナンス・解体を行う

### 型が変わる境目（一社の中で）

- **境目1（重点）：工程10 製作（repetitive_production）→ 工程13〜17 施工・設置（project_based）**。S1・S3 では同じ「製作・施工」職種の中で「製作」と「施工・設置」の2職務に分かれ、能力ユニットも完全に別（製作7：材料別の加工／施工・設置4：基礎・仮設・組立て設置・塗装防水）。両方にまたがる管理は「製作・施工管理」職種1つが担う（S3 p.16「製作・施工現場を統括」）。
- 境目2：工程6〜8 設計（project_based）→ 工程9〜10 製作（repetitive_production）。渡されるのは図面（S3「設計図面に基づき広告物を製作し」）。
- 境目3：工程11 自社→外注（型は変わらないが、組織の境界）。
- 境目4：工程16 設置（project_based）→ 工程20 管理・点検（after）。設置した広告物の管理・点検は資格者（屋外広告士）の役割として位置づけられる（S5）。

### 境目が無い場合もある

- 「小規模企業では、企画から施工まで一人の社員が担当するケースが多い」（S2）。「小規模事業所では一人が最初から最後まで制作を担うことも多く」（S4 就業ルート）。
- 「施工・設置のみに特化した企業」がある（S2）。この場合、製作は社外（他社）から渡される。

## B. 判断が分かれるところ（候補）

凡例：工程番号はAの表。分かれる理由は「経験差／基準の不在／情報の不足／前後工程との認識差」のどれか。

### B-1 現地調査で何を撮り、何を記録するか
- 工程：2 survey
- 何を見て何を決めるか：設置場所を見て、設計・製作・施工に必要な情報（写真・ビデオ、寸法、周辺状況）のうち何を持ち帰るかを決める
- 分かれる理由：基準の不在、前後工程との認識差。判定目安表のC（評価しない）例に「撮影漏れや自分勝手な方法など問題行動が何度もあった」とあり、何を撮るかが人によってばらつくことが評価項目になっている
- 出典：S3 p.18 判定目安表「写真・ビデオ撮影」のA/B/C例。S3 p.17 L1基準「広告設置場所の写真撮影やビデオ撮影を行う」。S4 タスク2（87.5%）

### B-2 地域の条例・法規に適合するかを、いつ、誰が確認するか
- 工程：2 survey／7 design
- 何を見て何を決めるか：設置地域の屋外広告物条例、建築基準法等を見て、看板の大きさ・形状・設置可否を決める
- 分かれる理由：情報の不足（条例は自治体ごとに異なる。L1基準は「設置する地域の条例等を確認する」と地域単位の確認を求めている）。JOB tag の「求められる資質」に「都道府県の条例の知識」が入る
- 出典：S3 p.17「広告物を設置する地域の条例等を確認する」。S4 タスク4（84.4%、重要度3.6）、求められる資質。S6 学科「関係法規」（1・2級は屋外広告物法・建築基準法・道路交通法・消防法・電気用品安全法、3級は屋外広告物法のみ）。S5 学科A「関係法規」

### B-3 形状とデザイン案をどう絞るか（複数案の提案）
- 工程：3 design
- 何を見て何を決めるか：設置場所の調査結果と依頼内容を見て、形状と複数のデザイン案を決める
- 分かれる理由：経験差。L1基準は「前例・類例のある簡単なケースで、与えられた範囲のデザインを作成する」までで、前例のない案件は上位レベルの仕事になる
- 出典：S4 タスク2「形状決定と複数デザインの提案」（87.5%）。S3 p.17「前例・類例のある簡単なケースで」。S6 実技「デザイン構成、レイアウト、レタリング」（1級は「高度なレタリング」）

### B-4 景観への配慮をどこまで織り込むか
- 工程：3〜6 design
- 何を見て何を決めるか：周辺の都市景観・広告景観を見て、依頼主の訴求とのバランスを決める
- 分かれる理由：基準の不在（景観は試験科目・資質として挙がるが、どこまでが適切かの線は資料にない）
- 出典：S4 求められる資質「景観への配慮」。S3 p.19 学科「広告デザインの基礎（景観論含む）」「景観との共生」。S5 学科B 試験基準「都市景観（特に広告景観）の専門知識」。S6 学科「広告景観（屋外広告と景観）」

### B-5 風圧・重量の計算を誰が、どの案件でするか
- 工程：7 design
- 何を見て何を決めるか：看板の大きさ・設置方法・設置場所を見て、構造計算が必要か、誰がするかを決める
- 分かれる理由：経験差、基準の不在。実施率は65.6%で20タスク中最低水準なのに重要度は3.4。屋外広告士試験では一級・二級建築士が学科C（設計・施工）と実技を免除される＝構造設計は建築士の領域と重なる
- 出典：S4 タスク16（65.6%、重要度3.4）。S5 試験科目の一部免除。S6 学科「安全に関する力学の基礎（力の三要素、モーメント、荷重、許容応力・安全率、断面係数、座屈 等）」（3級には力学の項目なし）

### B-6 積算・見積り（材料の種類判定を含む）
- 工程：4 intake
- 何を見て何を決めるか：デザイン・寸法・設置方法を見て、材料と工数を決め、金額にする
- 分かれる理由：経験差。技能検定では「材料の種類判定、積算および見積り」は1級の実技にのみ含まれ、2級・3級にはない＝上級技能者の仕事と位置づけられている
- 出典：S6 実技（1級のみ「塗料・材料の種類判定、積算・見積り」等）。S1「積算・見積り」ユニット（企画・営業）。S7 ディスプレイ業「見積り・採算性分析」「全体予算の見積り、予算折衝」

### B-7 図面を読み違えずに製作・施工できるか
- 工程：9〜10 production／16 install
- 何を見て何を決めるか：設計図を見て、加工・組立て・取付けの手順と寸法を決める
- 分かれる理由：経験差。判定目安表のC例に「簡単な図面でも読み違いが何度もあり」。設計→製作→施工は図面で渡される（S3 職務説明「設計図面に基づき広告物を製作し」）ので、読み違いは境目で起きる
- 出典：S3 p.18「図面読取り」A/B/C例、p.17「簡単な図面を誤りなく読み取る」。S6 学科「製作図（設計図の読み方、見取図・製作図の作成）」

### B-8 自社で作るか外注するか、外注先をどう管理するか
- 工程：11 production
- 何を見て何を決めるか：構造体の規模・自社の設備・納期を見て、外部業者に出すか決め、出した先の品質・納期を管理する

## C. 型の境目で起きること

### 境目1（重点）：製作（工場内）→ 施工・設置（現場）

**資料が言っていること**

- 職種は同じ「製作・施工」だが、職務は「製作」と「施工・設置」の2つに分かれ、能力ユニットは重ならない（S1）。製作側：画像出力・加工／金属加工／樹脂加工／木工加工／粘着シート加工／広告面ペイント／電気・照明製作。施工側：基礎工事／仮設工事／組立て・設置工事（メンテナンス、解体含む）／塗装・防水処理。
- 職務説明は「設計図面に基づき広告物を製作し、施工・取付け・設置・メンテナンス・解体を行う」（S3 p.16）。製作の入力は設計図面であり、施工の入力が何かは、この文には書かれていない。
- 両方にまたがる管理職種は「製作・施工管理」1つ。職務説明は「品質・原価・工程（納期）を管理し、安全・衛生に配慮しながら製作・施工現場を統括する」（S3 p.16）。ユニットは品質・原価・工程（納期）管理／購買・外注管理／安全・衛生管理の3つ（S1）。製作と施工の受け渡しそのものを扱うユニット名はない。
- レベル区分の呼称が職務で違う。製作のL3は「主任、職長・リーダー」、L4は「エキスパート、統括責任者、工場長」。施工・設置のL3は「主任」、L4は「エキスパート」（S2）。製作には「工場長」という上位呼称がある。
- 製作と施工の間にある工程は「運搬・搬入」で、JOB tag は「完成品をトラックで運び、クレーン車などで取り付ける」とする（S4）。モデルカリキュラムでは「運搬・搬入」が実施・構造設計実習の項目に置かれている（S3 p.19〜20）。
- 技能検定（製作側の資格）の学科「施工法一般」には「取付け方法（種類別、基礎、建造物、機械・器工具、仮設設備）」が含まれる（S6）。製作側にも取付けの知識が求められている。逆に屋外広告士（S5）の受験資格の実務経験は「屋外広告工事の施工等に従事した経験」で、屋外広告工事は「広告板、広告塔、ネオンサイン、ディスプレイ等の製作・設置を行う工事」と定義される。製作と設置を一体で「工事」と呼んでいる。

**前工程と後工程で「完了」の意味がどう違うか（資料から言える範囲）**

- 製作側の完了：図面どおりに広告物ができていること。技能検定の実技は「作業原稿の作成→仕上げ（カッティング／塗り込み／切断・組立て）」で終わる（S6）。設置は実技に含まれない。
- 施工側の完了：取り付けられ、「設置後、依頼内容に合っているか」が確認された状態（S4 タスク17）。照合先は「依頼内容」＝工程1の打合せで確認した設置場所・形態（S4 タスク1）。製作側の完了基準（図面）と施工側の完了基準（依頼内容）は、参照するものが違う。

**何が渡されて、何が渡されないか**

- 渡されるもの（資料に明記）：完成した広告物（S4）、設計図面（S3）。
- 渡されると書かれていないもの：設置場所の現地調査の情報（写真・ビデオ、S3）、依頼主の営業時間（夜間作業の判断材料、S4）、地域の条例の確認結果（S3）、近隣への説明の要否（S4）。これらは企画・営業またはデザイン・設計の工程で生じる情報であり、製作を経由して施工に届くルートは資料にない。
- 注意：上の「渡されない」は資料に書かれていないという意味であり、実際に渡されていないという事実ではない。

**実案件の仮説（製作＝反復生産型／施工＝個別受注型の受け渡しで認識差）について資料が支持する点・しない点**

- 支持する点：職務が別、ユニットが重ならない、上位呼称が別（工場長／エキスパート）、完了の参照先が別（図面／依頼内容）、間の工程「運搬・搬入」の置き場所がカリキュラム上あいまい（設計実習の項にある）。
- 資料が言っていない点：「反復生産」「個別受注」という型の違いそのもの、認識差が起きるという事実、何が食い違うか。これは照合役が実案件の field_evidence と突き合わせる領域。

### 境目2：設計（project_based）→ 製作（repetitive_production）

- 渡されるのは図面（S3「設計図面に基づき広告物を製作し」）。読み違いは評価項目（S3 p.18「図面読取り」）。
- 製作側の技能検定は「製作図（設計図の読み方、見取図・製作図の作成）」を学科に含む（S6）＝製作側が図面を読み、かつ製作図を起こす。
- 「画像出力・加工」ユニットはデザイン・設計と製作の両方に再掲されている（S1）。出力・カットの工程はどちらの職種がやってもよい設計になっており、会社ごとに置き場所が違いうる。

### 境目3：自社→外注

- 「展示用構造体の建設を外部業者に依頼」が87.5%（S4）。購買・外注管理は製作・施工管理職種のユニット（S1）。
- 外注先に何を渡すかは資料にない。ディスプレイ業では「外注管理」が4職種すべてに置かれ、どの工程からでも外注が出る前提になっている（S7）。

### 境目4：設置→管理・点検（after）

- 「組立て・設置工事」ユニットにメンテナンス・解体が含まれる（S1）。管理・点検は屋外広告士の資格の位置づけ（S5）。
- 設置時の完了確認（S4 タスク17）と、その後の点検の間に何が渡るかは資料にない。

## D. この業種にしかないもの／他業種にもありそうなもの

根拠は付けない。照合役が判定する。

### 業種固有と思われるもの
- B-2 地域の条例・法規適合の確認（屋外広告物条例が自治体ごとに違う）
- B-4 景観への配慮の線引き
- B-5 風圧・重量の計算（屋外構造物としての看板）
- B-9 調色・色合せ
- B-10 粘着シートの立体面への貼込み・はがし方
- B-13 取付けを夜間・閉店後にする判断
- B-18 電飾・ネオンの電気工事の線引き
- B-19 設置後の看板の落下リスク・点検

### 他業種にも同じ構造がありそうなもの
- B-1 現地調査で何を記録するか（電気工事、建設、内装）
- B-3 複数案の提案をどう絞るか（デザイン業、建築設計）
- B-6 積算・見積りが上級者の仕事（建設、製造の個別受注）
- B-7 図面の読み違い（製造、建設全般）
- B-8 自社でやるか外注するか（建設、製造）
- B-11 非定型の申請をどう作る（建設、電気工事）
- B-12 工程表を誰がどう引くか（個別受注の製造・建設）
- B-14 近隣住民への説明（建設、電気工事）
- B-15 設置後の「依頼内容に合っている」を誰が決めるか（個別受注型全般の close）
- B-16 安全規定に沿った機器操作（建設、電気工事、製造）
- B-17 基礎工事を自社でするか（電気工事、設備工事）

### 境目として他業種にも出そうなもの
- 境目1「工場で作る→現場で付ける」：電気工事（盤製作→現場施工）、建具・家具製造（JOB tag が類似職業に「家具製造、建具製造」を挙げる、S4）
- 境目2「図面で渡す」：製造・建設全般
- 境目3「外注」：全業種

## 付記：レベル軸の材料（カード化時に使う）

- 屋外広告業 L1〜L4（S2）：L1 基本的な知識・技能で定型的な日常業務／L2 担当業務全体を独力で／L3 主体的な判断や工夫で業務を取りまとめ、部下を指導／L4 会社の利益拡大や競争力強化に貢献。
- 技能検定の級差（S6）：学科は「詳細な知識」（1級）／「一般的な知識」（2級）／「概略の知識」（3級）。実技は、3級＝粘着シートのみ・平面まで、2級＝ペイント／プラスチック／粘着シートから選択・立体面あり、1級＝これに「高度なレタリング」「材料の種類判定」「積算・見積り」が加わる。
- 屋外広告士（S5）：実務経験3年以上、学科A法規／B広告デザイン／C設計・施工＋実技（設計またはデザイン）。合格基準は合計60%かつ科目ごとの足切り40%。業務主任者（営業所ごとに選任）の資格要件。
- JOB tag（S4）：入職後、一般的な就業者と同様に働けるまでの期間は「1〜2年」17.8%、「6ヶ月〜1年」15.6%、「2〜3年」15.6%が多い。入職前の訓練は「特に必要ない」48.9%。
