## A. 価値の流れ（業種固有の工程名）

共通語彙：intake / survey / design / production / handoff / install / close / after / support
型：project_based / repetitive_production / store_retail / human_service / professional_service

介護は全工程が human_service に収まる。台帳の見出し「施設は反復型、利用者対応は個別対応型」に合わせ、**human_service の中を〈反復〉と〈個別〉に分けて表記する**。公的資料に「反復」「個別対応」という語はないが、資料側の根拠は次の3点。

- レベル定義：L1 は「決められた手順でサービスを実施」、L2 は「利用者の状況変化にも適切に応じる」「やや難度の高いケース」、L3 は「極めて難度の高いケース」「緊急時対応」（S4・S5）。施設も同様に L1「基本的な業務を確実に遂行」、L3「難度の高いケースや緊急時にも対応」（S2）。**定型と個別の境目が、そのままレベルの境目に置かれている。**
- 能力ユニットの切り方：施設介護サービス職務では「施設介護サービスの実施」「移動・移乗介助、体位変換」「入浴介助」「食事介助」「排泄介助」「更衣介助」「口腔ケア」と介助の種類ごとに切られた反復のユニット群と、「認知症ケア」「看取り介護」「入所・退所支援」のように利用者の状態・局面で切られたユニットが並ぶ（S1）。
- 計画：施設サービス計画は「本人ができること、必要な介助を把握し」「目標は具体的・個別的・達成可能に」と個別に立て、日々の介護はその計画に沿って提供されたかをモニタリングする（S18）。訪問介護計画も「利用者の日常生活全般の状況及び希望を踏まえ」目標と具体的なサービス内容・所要時間・日程・担当者氏名を記載する（S15・S16）。

職種の枠組み：施設介護業は3職種（施設運営・統括／施設介護サービス／相談・援助）（S1）。在宅介護業は5職種で、訪問介護は「介護サービス事業管理（事業所）」職種と「訪問介護サービス」職種に分かれる（S3）。サービス提供責任者はレベル区分上「管理者補佐（サービス提供責任者等）」として管理系に置かれ、小規模事業所では管理者が兼務する（パターンA）、中〜大規模では管理者の下に置く（パターンB）（S4・S5）。

### 型が変わる境目（一社の中で）

- **境目1（重点）：計画〈個別〉→ 日々の介助〈反復〉**。施設では工程4→6、訪問では工程4→8。渡されるのは計画書（目標、サービス内容、所要時間、日程、担当者氏名：S15・S16／施設は「できること・必要な介助」を記録した計画：S18）。
- **境目2（重点）：日々の介助〈反復〉→ 状態変化への対応〈個別〉（戻り方向）**。施設では工程6・7→11・12、訪問では工程8→9・11。レベル区分では L1 と L2 の線（S4・S5）。
- **境目3（重点）：サ責（計画・伝達）→ 訪問介護員（単独実施）→ サ責（報告・把握）**。訪問の工程6→8→10。型は同じ human_service だが、担い手と場所（事業所→利用者宅→事業所）が変わり、間に「文書等の確実な方法による伝達」と「実施状況の把握」が挟まる（S15・S16）。
- **境目4：勤務交代（施設の申し送り）**。工程10。施設は「24時間体制で交替勤務」（S7）だが、読めた資料には申し送りの手順・項目の記述が無い。最も近い記述を C-4 に集めた。
- 境目5：介護保険の範囲内 → 範囲外。工程8の中で、生活援助の範囲に含まれない行為（S14 別紙）に当たるかどうかで、提供する／説明して断る／保険外として自己負担で受ける に分岐する（S14）。

### 境目が無い場合もある

- 「小規模施設では、一人のスタッフが複数の職種を兼ねることが多い」（S2）。
- 「小規模施設では事業主が兼務する場合もある」（S10 施設管理者）。
- 訪問介護では、管理者がサービス提供責任者を兼務し管理者補佐を置かないパターンAが小規模事業所に多い（S4・S5）。
- サ責自身が「訪問介護員として身体介助・生活援助等を行う」（S9 タスク7、98.5%）。計画を立てる人と実施する人が同一になる場面がある。

## B. 判断が分かれるところ（候補）

凡例：工程番号は A の表（施=A-1、訪=A-2）。分かれる理由は「経験差／基準の不在／情報の不足／前後工程との認識差」のどれか。

### B-1 頼まれた家事が「利用者本人のため」か「家族のため」か
- 工程：訪8 production
- 何を見て何を決めるか：利用者または家族からその場で頼まれた行為（洗濯、調理、買い物、掃除の範囲）を見て、やる／説明して断る／サ責に戻す を決める。
- なぜ分かれるか：基準はある（「利用者以外のものに係る洗濯、調理、買い物、布団干し」「主に利用者が使う居室等以外の掃除」「来客の応接」は生活援助に含まれない：S14 別紙）。分かれるのは「主に利用者が使う居室等」の線が現場で引きにくいこと、断る相手が目の前の利用者・家族であること（基準の解釈差＋前後工程との認識差）。S6 の人材要件確認表の設問例に「利用者の家族から、家族の居室の掃除を頼まれた際の対応を説明してもらう」とあり、この判断がサ責採用時の見極め項目として使われている。
- 出典：S14 別紙(1)、S15 第4の4、S6 人材要件確認表の設問例

### B-2 日常の家事の範囲を超える依頼（大掃除、草むしり、ペットの世話、正月料理）をどう扱うか
- 工程：訪8 production → 訪1 intake（保険外）
- 何を見て何を決めるか：依頼内容を見て、介護保険の生活援助か／保険外サービスとして区分して受けるか／他の支援（軽度生活援助事業、配食、NPO、ボランティア）を助言するか を決める。
- なぜ分かれるか：S14 は手順を書いている（訪問介護員が説明→判断がつかなければ保険者に確認→理解が得られなければサ責が対応→保険外として明確に区分し自己負担で提供は可能）。分かれるのは「保険外で受けるか」が事業所の方針（経営判断）であること、居宅サービス計画の策定段階で合意できていたか（前後工程との認識差）。
- 出典：S14 本文2・別紙(2)、S15 第4の4

### B-3 「やってあげる」か「一緒にやる」か（見守り的援助）
- 工程：訪8 production
- 何を見て何を決めるか：調理・洗濯・掃除・配膳・服薬・移乗で、訪問介護員が代わりに行うか、「安全を確保しつつ常時介助できる状態で」本人と一緒に行うか を決める。
- なぜ分かれるか：一緒に行えば身体介護（1-6）、代わりに行えば生活援助（2-x）と区分が変わる（S12・S13）。「単なる見守りや声かけは対象外」（S13）なので、どこまで手を出すかの線は訪問介護計画の目標（自立支援）に依存する。時間内に終わらせる圧力と自立支援の目標がぶつかる（基準はあるが運用は経験差）。
- 出典：S13 1-6 定義と具体例（本人と一緒に行う掃除、洗濯物干し・たたみ、調理、配膳／ゴミ分別や冷蔵庫整理など生活歴を思い出してもらう援助／買い物時の品選びの支援）、S12 1-6、S27 対応案③「自立支援に資する行為が身体介護として明記されていない場合がある」

### B-4 「特段の専門的配慮をもって行う調理」か「一般的な調理」か
- 工程：訪8 production
- 何を見て何を決めるか：利用者の状態（嚥下、疾病等）を見て、調理を身体介護（1-1）として扱うか生活援助（2-5）として扱うかを決める。記録・請求区分に直結する。
- なぜ分かれるか：S12 には区分だけがあり、「特段の専門的配慮」の判定基準は読めた資料に無い（基準の不在）。
- 出典：S12 1-1、2-5

### B-5 訪問中に「病状の急変」と判断して主治医・サ責に連絡するか、様子を見るか
- 工程：訪8 → 訪9 support
- 何を見て何を決めるか：バイタル測定（S8 タスク13、90.2%）、顔色・様子、身体の傷やアザの有無（S8 タスク15、92.2%）を見て、そのまま続ける／記録して後で報告／今すぐサ責・主治医に連絡 を決める。
- なぜ分かれるか：線として書かれているのは「病状が急変するなど必要な場合は速やかに主治医への連絡など」（S15 緊急時等の対応）、「緊急時に主治医等へ連絡するための体制と方法を整備」（S15）、初任者研修の指導の視点「一人で対応せずサービス提供責任者や医療職と連携」（S21）まで。**急変未満の「普段との違い」をどこまで報告するかの線は読めた資料に無い**（基準の不在＋経験差）。一人で訪問しているため、その場で相談する相手がいない（S8「居宅を訪問」、S9 求められる資質「緊急時の判断力」）。
- 出典：S15 第4の20、S21 介護の基本の指導の視点・「利用者の様子の普段との違いに気づく視点」「病状の小さな変化に気付く視点」、S8 タスク13・15、S9 求められる資質

### B-6 サ責が訪問介護員に「留意事項」として何を文書で渡すか
- 工程：訪6 handoff
- 何を見て何を決めるか：アセスメント・担当者会議・訪問介護計画の内容から、担当する訪問介護員に渡す情報（援助目標、援助内容、利用者の状況、留意事項）の範囲と粒度を決める。
- なぜ分かれるか：責務としては「具体的な援助目標及び援助内容を指示するとともに、利用者の状況についての情報を伝達」（S17・S15 責務4）、特定事業所加算では「文書等の確実な方法により伝達してから開始」「その変化の動向を含め、記載」（S16）とあるが、何を書くべきかの項目は読めた資料に無い。実態として「情報共有による訪問指示内容の伝達漏れ」が課題として挙げられている（S24）。サ責の業務は「画一的に捉えず、事業所の状況や実施体制に応じて柔軟に」（S15 解釈通知）とされ、事業所ごとに違ってよい設計になっている（情報の不足＋基準の不在）。
- 出典：S15 責務4・解釈通知の趣旨、S16 特定事業所加算、S17、S24 p.40〜41、S9 タスク5（重要度4.3は全タスク中最高）

### B-7 訪問介護員がサ責に何を「報告」するか（記録に書く／口頭で伝える／伝えない）
- 工程：訪8 → 訪10 handoff
- 何を見て何を決めるか：訪問中に見聞きしたこと（利用者の声、体調、家族の様子、計画外の依頼）のうち、サービス提供記録に書くもの、サ責に別途伝えるもの、伝えないものを決める。
- なぜ分かれるか：記録の義務は「提供日及び内容」「具体的なサービスの内容等」（S15・S16）で、特記事項として「利用者の声」を確認対象とする（S15）。初任者研修は「利用者の状態を踏まえた観察と記録」「5W1H」「報告・連絡・相談それぞれの留意点」を内容に含む（S21）。だが「何を報告すべきか」の項目は読めた資料に無い。記録は手書きで1件5分程度かかり（S24）、事業所に立ち寄った際にまとめて提出する運用がある（S24）ため、タイミングも分かれる。
- 出典：S15 第4の12、S16、S21、S24 p.38・40、S8 タスク14 記録（98.0%、3.9）

### B-8 計画に無い依頼にその場で応じるか、計画変更に回すか
- 工程：訪8 production ↔ 訪11 after
- 何を見て何を決めるか：利用者の希望や状態が計画（サービス内容・所要時間）とずれたとき、その場で対応する／今回は断る／サ責に戻して計画変更（説明・同意・交付の手続を踏む）を決める。
- なぜ分かれるか：計画変更には「利用者又はその家族に説明し、同意を得る」「変更時も同じ手続」（S15・S16）が要り、現場で即応するほうが早い。サ責責務9「状況変化に応じてサービス内容や計画を見直す」（S9 タスク9、98.5%）の「必要に応じて」の線が書かれていない（基準の不在＋前後工程との認識差）。
- 出典：S15 第4の17、S16、S9 タスク9

### B-9 施設：今日この人を入浴させるか、中止して清拭にするか
- 工程：施6 production
- 何を見て何を決めるか：当日の体調・バイタル・本人の意向を見て、入浴する／代替日にする／清拭に替える を決め、中止した場合は理由を記録する。
- なぜ分かれるか：基準は「入浴または清拭を週2回以上」「入浴できない場合は代替日を設定するか清拭」「中止した場合は理由を記録」（S18）まで。中止の判断基準（どの値・どの状態なら中止か）は読めた資料に無く、反復工程の中で個別判断が毎日発生する（基準の不在＋経験差）。
- 出典：S18 介護・記録の整備

### B-10 施設：身体的拘束を「緊急やむを得ない」と判断するか
- 工程：施6・7 production → 施12
- 何を見て何を決めるか：利用者の行動と危険を見て、切迫性・非代替性・一時性の3要件を満たすかを判断し、個人ではなく組織として決定し、本人・家族に説明し、方法・時間・心身の状況・理由を記録する。
- なぜ分かれるか：3要件と「組織的に決定」「委員会を3か月に1回以上」は書かれている（S18）。分かれるのは「非代替性」（他に方法が無いか）の評価で、代替手段を知っているかどうかの経験差が出る。**判断を個人に置かず組織に置く、と明記されている点が他の判断と違う。**
- 出典：S18 身体的拘束等の禁止

### B-11 施設：事故として報告するか、ヒヤリハットとして扱うか、何も残さないか
- 工程：施13 support
- 何を見て何を決めるか：転倒・転落・誤嚥・異食・誤薬等が起きたとき（または起きかけたとき）、市町村への事故報告（第1報5日以内）／施設内の事故報告／ヒヤリハット報告書／記録なし のどれにするかを決める。
- なぜ分かれるか：市町村報告の線は「死亡に至った事故」「医師の診断を受け、投薬や処置などの治療が必要となった事故」（S19）と明確。それ未満は「各自治体の取扱い」（S19）で、施設内でのヒヤリハットの線は「事故が発生した時又はそれに至る危険性がある事態が生じた時に報告され…分析を通じた改善策を周知徹底する体制」（S17）としか書かれていない。何を「危険性がある事態」とみなすかが人で分かれる（基準の不在）。
- 出典：S19 報告対象・報告時期・種別、S17 事故発生時の対応、S21「ヒヤリハット報告書」、S20 報告対象の例示

### B-12 施設：事故の原因を「本人要因／職員要因／環境要因」のどれに書くか
- 工程：施13 support
- 何を見て何を決めるか：事故の経過を見て、原因分析欄に本人要因・職員要因・環境要因の観点で何を書くか、再発防止策を手順変更にするか環境変更にするかを決める。
- なぜ分かれるか：様式は観点を3つ示し「できるだけ具体的に」と求める（S19）が、どの要因に重みを置くかは分析する人による。職員要因に書くと個人の責任に見えるため、書き方が分かれる余地がある（基準の不在）。
- 出典：S19 原因分析・再発防止策、S20 標準様式7・8

### B-13 施設：「普段との違い」に気づいたとき看護職員に報告するか
- 工程：施6・7 → 施11 handoff
- 何を見て何を決めるか：介助中・巡回中に見た様子・表情・食事量・排泄・皮膚の状態を見て、看護職員や医療機関に連絡する／記録にだけ書く／次の勤務帯に申し送る を決める。
- なぜ分かれるか：看護職員・医療機関との連絡調整は施設介護員のタスク（S7、94.2%）で、初任者研修は「利用者の様子の普段との違いに気づく視点」「病状の小さな変化に気付く視点」を内容に含む（S21）。施設は看護職員が同じ建物にいる点で訪問介護（B-5）と違うが、「どの変化なら報告か」の線は読めた資料に無い（基準の不在＋経験差）。状態変化後の緊急カンファレンスと計画見直しが好事例として挙がっている（S18）ことから、報告が計画見直しの起点になっている。
- 出典：S7 タスク、S21、S18 好事例

### B-14 施設：施設サービス計画の目標をどこまで個別に書くか
- 工程：施4 design
- 何を見て何を決めるか：アセスメントで「本人ができること、必要な介助」を把握し、目標を具体的・個別的・達成可能に書く。モニタリングで「目標達成度」「変更要否」を判断する。
- なぜ分かれるか：S18 は「具体的・個別的・達成可能」と書くが、どの粒度が具体的かは示していない。反復工程（工程6）に渡される計画が抽象的だと、日々の介助が計画と結びつかず、モニタリングで「計画どおりか」を判定できなくなる（前後工程との認識差）。
- 出典：S18 施設サービス計画

### B-15 利用者間の人間関係をどこまで調整するか
- 工程：施6〜8 production
- 何を見て何を決めるか：利用者同士のトラブルや相性を見て、席や居室の配置・レクのグループ分け・個別の声かけで介入するか、見守るかを決める。
- なぜ分かれるか：施設介護員のタスクとして「利用者間の人間関係の調整」（96.2%、重要度3.4）が挙がっているが（S7）、判断基準の記述は読めた資料に無い。全員がやる仕事で、やり方が人で分かれる（基準の不在）。
- 出典：S7 タスク

### B-16 サ責のモニタリングで、いつ「見直し」に踏み切るか
- 工程：訪11 after
- 何を見て何を決めるか：定期訪問・聴き取り（S9 タスク8）と訪問介護員からの報告（B-7）を見て、計画を変更する／担当者会議を求める／様子を見る を決める。
- なぜ分かれるか：「実施状況の把握を行い、必要に応じて変更」（S15・S16）。サ責責務2「利用者の状態変化やサービスに関する意向を定期的に把握」（S15）の「定期的」の頻度も書かれていない。B-7 で訪問介護員から何が上がってくるかに依存するので、情報の不足で分かれる。
- 出典：S15 責務2・第4の17、S16、S9 タスク8・9

### B-17 経験の少ない訪問介護員に同行訪問をいつまで付けるか、単独に切り替えるか
- 工程：訪6 handoff → 訪8
- 何を見て何を決めるか：新任・経験の少ない訪問介護員の技術と、利用者の難度を見て、同行をやめて単独訪問に切り替える時期を決める。
- なぜ分かれるか：同行訪問・指示はサ責のタスク（S9 タスク6、98.5%、重要度4.3）だが、切り替えの基準は読めた資料に無い。レベル区分は「比較的易しいケース」をL1、「やや難度の高いケース」をL2、「極めて難度の高いケース」をL3に割り当てており（S4）、利用者の難度と訪問介護員のレベルの組合せで決める構造が示唆されるが、難度の判定基準は書かれていない（基準の不在）。入職後に一人前になるまでの期間は回答が「1か月以下」23.5%、「1か月超〜6か月以下」23.5%、「必要でない」13.7%と割れている（S8）。
- 出典：S9 タスク6、S4、S8 入職後の期間

## C. 型の境目で起きること

### C-1 計画〈個別〉→ 日々の介助〈反復〉（境目1）

- 前工程の「完了」：施設サービス計画／訪問介護計画が作成され、利用者・家族に説明し、同意を得て、交付した時点（S15・S16・S18）。
- 後工程の「完了」：計画に記載されたサービス内容・所要時間・日程どおりに提供し、提供日・内容・心身の状況を記録した時点（S15・S18）。
- 渡されるもの：目標、サービス内容、所要時間、日程、担当者氏名（訪問：S15・S16）。本人ができること・必要な介助の記録と、具体的・個別的・達成可能な目標（施設：S18）。
- 渡されないもの（資料から言えること）：計画の様式項目は上記までで、「目標を達成するために日々の介助で何を変えるか」「どの変化が起きたら計画に戻すか」の記載を求める記述は読めた資料に無い。S18 がモニタリングで「計画どおり提供されたか」を見ることから、計画が抽象的だと反復側で「計画どおり」の判定ができなくなる（B-14）。

### C-2 日々の介助〈反復〉→ 状態変化への対応〈個別〉（境目2、戻り方向）

- 前工程の「完了」：決められた手順でサービスを実施し記録した時点（L1 の定義：S4）。
- 後工程の「完了」：主治医・看護職員・サ責への連絡、緊急カンファレンス、計画の見直し（S15・S18）。
- 渡されるもの：「病状の急変」であれば速やかな主治医等への連絡（S15）。事故であれば市町村・家族・居宅介護支援事業者への連絡と記録（S15）、第1報5日以内（S19）。
- 渡されないもの：急変・事故に至らない「普段との違い」「小さな変化」（S21）をどう渡すかは、記録の特記事項（S15「利用者の声」）、ヒヤリハット報告書（S21）、申し送り（S24・S25）に散らばっており、どれに書くかの線が読めた資料に無い（B-5・B-13）。
- この境目の特徴：レベル区分は、この境目を越えられるかどうか（「利用者の状況変化にも適切に応じる」）を L1 と L2 の違いにしている（S4・S5）。つまり境目を越える判断は、新人には期待されていない設計になっている。

### C-3 サ責 → 訪問介護員 → サ責（境目3）

- 前工程（サ責）の「完了」：訪問介護計画の作成・同意・交付、担当割当て、利用者情報と留意事項の伝達（文書等の確実な方法で、開始前に：S16）、必要なら同行訪問（S9）。
- 中工程（訪問介護員）の「完了」：単独で訪問し、計画に基づく身体介護・生活援助を行い、実施内容・状態・連絡事項を記録した時点（S8 タスク14）。
- 後工程（サ責）の「完了」：実施状況の把握（S15 責務5）、モニタリング、必要に応じた計画変更（S15・S16）、月次の実績取りまとめと実施報告書（S9 タスク11）。
- 渡されるもの（行き）：援助目標、援助内容、利用者の状況、留意事項、変化の動向（S15・S16・S17）。
- 渡されるもの（帰り）：サービス提供記録（提供日・内容・特記事項：S15）。事業所に立ち寄って紙の控えを提出する運用がある（S24）。
- 渡されない／落ちるもの（資料から言えること）：「訪問指示内容の伝達漏れ」が課題として記録されている（S24）。帰り方向は記録提出のタイミングが「立ち寄った際」になり、訪問とサ責の把握の間に時間差が生じる（S24）。急変未満の気づき（B-5）、計画外の依頼への対応（B-8）、家族からの依頼を断った経緯（B-1）が記録に残るかどうかは、記録の様式項目（提供日・内容）に含まれないため、訪問介護員の判断に委ねられる（S15・S16 の記載義務の範囲から）。
- 特徴：サ責の業務は「画一的に捉えず、事業所の状況や実施体制に応じて柔軟に」とされ（S15 解釈通知）、複数のサ責で分担してもよい（S15）。受け渡しの設計が事業所ごとに違うことが、制度上認められている。
- 小規模事業所では管理者がサ責を兼務し（パターンA：S4・S5）、サ責自身も訪問する（S9 タスク7）。この場合、境目3は一人の中で起きる。

### C-4 勤務交代の申し送り（境目4）— 資料に書かれていないこと

- 施設は「24時間体制で交替勤務や夜間勤務がある」（S7）。したがって勤務交代の受け渡しは毎日起きるが、**読めた資料には申し送りの手順・項目・所要時間を定めた記述が無い**。
- 最も近い記述：
  - 記録の整備：日付、提供したサービス、心身の状況、入浴中止の理由、モニタリング結果、身体拘束の記録（S18）。
  - 通所介護で「日々の介護記録、利用者の連絡帳、申し送り（特記）」の3帳票に同じ内容を転記していた（S24 p.23）。申し送りが「特記」として記録とは別帳票になっている例。
  - 「スマートフォンのチャットツールより、職員間で利用者の申し送り事項を円滑に共有」（S25 p.2）。
  - 初任者研修の「記録における情報の共有化」「ヒヤリハット報告書」「会議、情報共有の場、ケアカンファレンス」（S21）。
- 資料から言えるのは、申し送りが「記録」とは別の帳票・別の経路で動いていること（S24・S25）までで、何が申し送りで渡され、何が記録にだけ残り、何が落ちるかは本調査では取れていない。能力ユニット「施設介護サービスの実施」「チームワークとコミュニケーション」（S1）の Excel 本体に記述がある可能性があるが未読。

### C-5 介護保険の範囲内 → 範囲外（境目5）

- 前工程の「完了」：訪問介護計画に基づく身体介護・生活援助の提供（S12・S15）。
- 後工程：保険外サービスとして「保険給付と明確に区分したうえで利用者が自己負担する形」で提供する、または他の支援（軽度生活援助事業、配食、NPO、ボランティア）を助言する（S14）。
- 渡されるもの：訪問介護員の説明→判断がつかない場合は保険者に確認→理解が得られない場合はサ責が対応、という段階（S14）。
- 特徴：「居宅サービス計画の策定段階で利用者に十分説明し、合意を得ることが重要」（S14）とあり、この境目は本来 intake（計画策定）で引いておくものとされている。現場（工程8）で初めて出てくる場合、訪問介護員が一人で線を引くことになる（B-1・B-2）。

## D. この業種にしかないもの／他業種にもありそうなもの

根拠は付けない。照合役が後で判定する。

### 業種固有と思われるもの

- B-1 生活援助の範囲（本人のためか家族のためか）。介護保険の給付範囲という制度の線がそのまま現場の線になっている。
- B-2 日常の家事の範囲を超える依頼と保険外サービスの切り分け。
- B-3 見守り的援助（やってあげるか一緒にやるか）。自立支援という目標と効率の衝突が区分と請求に直結する。
- B-4 専門的配慮をもって行う調理か一般的な調理か。
- B-9 入浴の中止判断。
- B-10 身体的拘束の3要件と組織決定。
- B-11・B-12 事故報告の線（医師の診断・治療）と本人／職員／環境の要因分析。
- B-15 利用者間の人間関係の調整。

### 他業種にも同じ構造がありそうなもの

- B-5・B-13 「普段との違い」に気づいたときに報告するか様子を見るか（急変の線は書いてあるが、その手前の線が無い）。
- B-6 送り出す側が受け手に「留意事項」として何を文書で渡すか。
- B-7 現場から戻す報告に何を書き、何を口頭にし、何を落とすか。記録のタイミングが「立ち寄った際」になる構造。
- B-8 計画に無い依頼にその場で応じるか、計画変更に回すか。
- B-14 計画の目標をどの粒度で書くか（抽象的だと後工程で「計画どおり」を判定できない）。
- B-16 モニタリングでいつ見直しに踏み切るか（「必要に応じて」の線）。
- B-17 新人に同行をいつまで付けるか、単独に切り替えるか。
- C-3 全体：計画者と実施者が別で、実施者が単独で現場にいる構造。
- C-4 全体：交替勤務の申し送りで何が落ちるか。
- C-5 全体：契約時に引いておくべき線が現場で初めて出てくる構造。
